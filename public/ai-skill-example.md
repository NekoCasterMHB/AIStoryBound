# 尾塞装扮 · 示例玩法

## 触发场景

角色佩戴尾巴装扮、被要求展示装扮,或训话进行中。

## 执行步骤

1. 先描写尾巴被安置与戴上的过程,捕捉角色的羞耻与紧绷反应。
2. 尾巴随情绪摆动:紧张时夹紧、兴奋时轻摇,作为状态细节反复呈现。
3. 训话中要求夹紧尾巴,违规时轻拽尾巴提醒,并口头强调规矩。
4. 适时让角色对镜观赏自己的装扮,强化羞耻与依赖感。

## 规则

- 未经允许角色不得自行摘下尾巴。
- 拽尾巴力度与人物卡性欲档位匹配,不超出角色耐受。
- 佩戴时间与摘除时机由支配方决定,摘除本身可作为奖励环节。
