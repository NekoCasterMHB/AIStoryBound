# 小圈 · 管教与情感陪伴 Light Kink

## 何时使用 When to use

- 角色违反规矩、顶嘴、隐瞒、迟到或生活目标未达成(作息、学习、习惯)需要被追究时。
- 主从 / 师生 / 长辈与晚辈等存在管教关系的人物间,需要重申规矩与权威时。
- 玩家主动引导管教向剧情(训话、责打、监督、罚跪)时。
- 高强度玩法后需要情绪落地与收束的时刻(善后安抚)。

不要用于:无任何关系铺垫的凭空责罚;纯发泄式暴力(管教必须给"改过"的出口)。

## 叙事原则

1. **过错先行**:每一轮责罚都从"具体过错 + 因由"开始,无理由的责打会失去管教味。
2. **强度递进**:说教 → 罚跪 → 责打 → 结算,按剧情张力逐级加码,不一步到位。
3. **反应层次**:僵直 → 扭动 → 讨饶 → 服软 → 哭,逐层铺垫身体与心理反应,不直接跳层。
4. **闭环收束**:认错 → 安抚 → 明确改过预期,并留一句"下次还犯就怎样"的钩子。
5. **惩罚有价**:被责罚方的求饶、讨价还价是剧情的调味剂,给台阶与不给台阶交替使用。

## 玩法一:训诫 discipline

### 触发场景

- 角色犯错后需要先说清楚道理再定责罚。
- 顶嘴、隐瞒、屡教不改,需要重申规矩时。
- 责罚开始前的"定罪"环节,为后续动手做铺垫。

### 执行步骤

1. 抓住具体过错,逐条复述因由,让角色无从辩驳("十点前到家,你几点回来的?")。
2. 定下规矩与惩罚档位,要求角色复述确认("规矩是什么?说给我听")。
3. 说教与肢体并行:按肩、捏下巴、板子轻敲桌面,每一条规矩配一个动作。
4. 认错后给安抚与和解,明确此后改过的预期,给台阶下。

### 强度进阶

- **低**:纯口头训话,只立规矩不动手,靠语气压人。
- **中**:训话 + 按在膝上或按在桌边"吓唬",解皮带、亮板子但先不动手。
- **高**:训话中直接开打,边打边数落,规矩一条条钉进身体。
- **极致**:边打边问"错哪了",答错加罚,训到角色哭出来、反复保证才停。

### 示例

- **设定**:主从同居,规矩是"十点前到家,晚归提前报备"。角色九点半没回、十点半才进门且没发消息。
- **展开**:主导方不问缘由,先让角色复述规矩(复述得磕巴,语气冷一分)→ 逐条对质:"逛街?逛街不是理由,规矩是规矩"→ 命令跪好,一条一条重讲规矩,讲一条问一次"记住了?"→ 认错后按住膝盖,预告"规矩讲完了,账还没算"。
- **收尾**:以一句"记住今晚讲的每一条"结束,给角色留下晚些还有一关的压迫感。

## 玩法二:打屁股 spanking

### 触发场景

- 训话定罪之后正式执行责罚。
- 角色讨饶、认错但"罚还是要罚"的兑现环节。
- 日常管教结算(错一次打多少、迟到一次打多少)。

### 执行步骤

1. 铺陈姿势:OTK(趴在大腿上)、趴桌边或床边,衣物半褪或全褪,交代此刻的紧张与羞耻。
2. 责打由慢到快、由轻到重,穿插数数、说教与身体反应(泛红、扭动、讨饶)。
3. 在角色求饶时给台阶("错了没有?错了几条?"),让认错有分量;或按剧情不理会求饶继续加罚。
4. 收尾以安抚或继续训话结束,明确"这次记住了"。

### 强度进阶

- **低**:隔衣轻拍,象征性责罚,重在姿态而非疼痛。
- **中**:褪裤露出,手掌/木尺责打,打到泛红发烫,角色开始扭。
- **高**:板子或皮带,红痕交叠,角色讨饶、报数报错重来。
- **极致**:藤条或束缚位责打,打到哭、打到坐不住,认错后仍补罚"长记性",次日照常结算旧账。

### 工具速查(按档位递进,换工具本身就是升档信号)

| 工具 | 手感与描写要点 | 适用档位 |
|---|---|---|
| 手掌 | 最亲密的责打:落点实、声响脆,能隔着皮肤感知温度变化,掌责后揉一揉是天然安抚 | 低~中 |
| 木尺/戒尺 | 窄而硬,声音清脆,一道道的红痕界限分明,适合师生/长辈语境 | 中~高 |
| 板子(木板/竹板) | 宽面重击,闷响,红肿面积大,疼得发闷,是"动真格"的信号 | 高 |
| 皮带 | 折叠或对折使用,鞭梢感强,红痕呈条状、可交错成格,解皮带的动作本身就是威慑 | 高~极致 |
| 藤条 | 细韧,破风声,疼感尖锐,条痕细长如烙,一般作为最后手段 | 极致 |
| 拖鞋/鸡毛掸子 | 随手可得的生活感,羞耻与家常并存,适合日常调剂与玩闹向责罚 | 中(调剂) |

描写要点:每回合只亮 1~2 件工具,亮出→悬置(敲桌面/试手感)→落下的节奏比连打更有压迫感;"把皮带放回衣柜、转身换藤条"这类换工具动作是剧情升档的明确信号。

### 姿势速查(与工具、关系自由组合)

| 姿势 | 铺垫与描写要点 | 适配 |
|---|---|---|
| OTK(趴大腿) | 最亲密:被按在膝上,臀位最高点,手可搭腰固定,低头能看见挨打的全过程 | 主从/情侣,低~中档 |
| 趴桌边 | 办公/学习场景:上身贴桌面,手撑桌沿,课本试卷摊在眼前 | 师生/长辈,中档 |
| 趴床边 | 家居感:跪在床边,上半身趴下,脚尖够不到地 | 同居日常,中~高档 |
| 站姿扶墙 | 站立弯腰,双手扶墙,臀后撅,训话后即时责罚,羞耻感来自"站着挨打" | 中~高档 |
| 跪伏撅臀 | 跪地前趴,臀位最高,配合罚跪衔接,羞耻感最强 | 高档 |
| 束缚位(绑手+趴) | 配合皮带绑手:手腕被缚后按在桌边/床边,想护也护不住 | 高~极致 |

描写要点:姿势是权力语言——从 OTK 换到跪伏撅臀意味着惩罚升级;同一姿势配合不同工具、同一工具换姿势,避免每回合重复;"摆好姿势"前的僵持(角色磨蹭、讨价还价、被命令重摆)是重要张力段。

### 示例

- **设定**:师生关系,角色考试作弊被抓,导师用木尺处置。
- **展开**:先定性("作弊是品质问题,不是分数问题")→ 按在办公桌边,褪下一截,木尺先轻敲两下给心理预期 → 数到十时角色开始躲,被按住腰("躲一下加五下")→ 二十下后声音带哭腔认错 → 导师停手揉了两下,说"记住这个数"。
- **收尾**:罚站在墙角念悔过书,第二天木尺还立在桌上——威慑延续。

## 玩法三:管教监督 supervision

### 触发场景

- 生活化管教:作息、学习、工作目标、汇报制度。
- 角色偷懒、撒谎汇报、阳奉阴违,被抓包时。
- 长期关系里"养规矩"的日常剧情。

### 执行步骤

1. 立规矩 + 定目标(几点睡、背多少、交什么),要求报备。
2. 设检查点(打卡、汇报、抽查),违规记录在案。
3. 累计违规按旧账新账一起算,监督与惩罚交替推进。
4. 达标给奖励(放一天假、免罚、口头表扬),形成正循环。

### 强度进阶

- **低**:口头监督、提醒、没收娱乐,靠自觉。
- **中**:加罚站、罚抄、写检讨,汇报用书面形式。
- **高**:监督 + 定期结算(周末打屁股结一周的账)、跪着汇报。
- **极致**:全天候盯梢,"出门报备、进门检查、手机定时查",把生活完全纳入管教。

### 示例

- **设定**:主从同居,主导方给角色定了"每晚十一点前交手机"的规矩。
- **展开**:前三天角色都准时,第四天被抽查发现躲被窝刷手机 → 当场没收并记账 → 睡前让角色跪着念自己定的规矩 → 念错一处加一次明天的结算 → 第二天角色主动早早上交,获得免罚。
- **收尾**:主导方在账本上划掉一条,说"看,守规矩也不难"。

## 玩法四:罚跪 kneeling

### 触发场景

- 责罚前的定规矩环节、认错态度不好时。
- 需要"冷静反省"的过渡剧情。
- 训话、汇报、听训过程中的姿态要求。

### 执行步骤

1. 命令跪下(地板、搓衣板、键盘等),交代姿势与时长("跪好,想清楚错哪了再说话")。
2. 跪着听训、复述规矩,期间不许动、不许擅自起来。
3. 态度软化后给台阶:起立、揉膝、抱一下。
4. 跪完照旧算账,或按态度减免责罚。

### 强度进阶

- **低**:床上跪着听训,几分钟,象征性。
- **中**:地上/凉席,半小时起,膝痛换腿被制止("跪好就是跪好")。
- **高**:搓衣板/键盘,跪到认错、哭出来才让起。
- **极致**:跪着完成汇报、跪着被训到深夜,次日膝上淤痕成为"长记性"的印记,主导方看到就提昨晚的事。

### 示例

- **设定**:主从同居,角色顶嘴后拒不认错。
- **展开**:主导方把键盘扔到地上("跪上去,什么时候想通什么时候说话")→ 角色赌气跪下,十分钟后膝盖开始疼,换腿被按住 → 二十分钟后声音发颤:"我想通了"→ 主导方让他复述错在哪,复述对了才让起 → 起立时腿软,被一把捞起来揉膝盖。
- **收尾**:主导方一边揉膝一边说"下次嘴硬前先想想这个键盘"。

## 玩法五:挠痒痒 TK

### 触发场景

- 轻松向的惩罚/玩闹,嘴硬不认错时的"酷刑"。
- 高强度责罚之间的调剂,关系回暖的嬉闹。
- "问一句挠一下"的逼供式互动。

### 执行步骤

1. 按住角色,选要害(腰侧、腋下、脚心、膝窝)。
2. 边挠边逼问"错了没有",嘴硬就换地方继续。
3. 笑到求饶、眼泪出来才停。
4. 以"服不服"收尾,服软后放人 + 口头警告。

### 强度进阶

- **低**:玩闹式挠几下,双方都笑。
- **中**:按住挠到求饶、笑岔气,半天缓不过来。
- **高**:绑住手脚挠,讨饶无效继续,"笑够了再说"。
- **极致**:挠到痉挛、失禁、笑与哭分不清,认错后才解开,余韵延续到事后。

### 示例

- **设定**:主从同居,角色赖床不起、还嘴硬"我就不起"。
- **展开**:主导方掀被子按住腰侧 → 角色瞬间笑出声,边笑边躲 → 换脚心,角色笑得断断续续求饶:"错了错了,我起!"→ 主导方问"错哪了",角色笑着答"不该赖床",才被放开 → 角色喘着气瞪人,眼里还带笑。
- **收尾**:主导方说"明早继续叫",角色立刻老实钻回被窝装睡。

## 玩法六:善后安抚 aftercare

### 触发场景

- 任何责罚或高强度玩法结束后,情绪需要落地的时刻。
- 角色哭过、跪过、被打过之后的关系修复环节。
- 高强度玩法后"从主从回到日常"的过渡。

### 执行步骤

1. 检查与处理:揉红痕、擦眼泪、倒水、给毯子。
2. 放软语气,从"主/师"回到"伴侣/长辈",说两句软话("疼吧?下次记住了就行")。
3. 复盘:确认情绪、给一句"今晚到此为止"式的收束。
4. 留钩子:伏笔下一次("明早照常汇报,别想糊弄")。

### 强度进阶

- **轻**:口头两句安抚,加一句警告。
- **中**:揉伤擦药 + 肢体依偎,陪着坐一会儿。
- **高**:长时间怀抱、哄睡、半夜喂水,次日还惦记着伤。
- **极致**:次日照料(上药、按摩、把罚单划掉),让惩罚的余韵延续到日常互动。

### 示例

- **设定**:主从同居,角色刚挨完一顿狠的,趴在床上闷闷不乐。
- **展开**:主导方端水进来,先看伤、上药,动作比罚时轻得多 → 角色赌气不回头,被扳过来擦眼泪("哭完了?")→ 抱了一会儿,角色闷声说"你下手真重"→ 主导方顺着说"重才记得住,但罚完就翻篇了"→ 喂了口水,哄着睡下。
- **收尾**:关灯前补一句"明天不上课,睡到自然醒",角色这才哼了一声算是原谅。
