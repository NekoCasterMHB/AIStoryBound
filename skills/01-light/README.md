# 小圈 · 01-light 玩法说明

## 类定义

小圈是以"管教"为核心的成人互动玩法体系:围绕"过错 → 责罚 → 认错 → 和解"闭环展开,**无性**,强度轻,情感底色是关怀与纠正——像严厉但疼人的兄长、导师、长辈。主/被关系可为主从、师生、长辈与晚辈、情侣日常。

## 判定标准

- 管教向叙事(立规矩、追责、认错、改过) → 小圈
- 出现口舌、玩具、手指等性刺激 → 升入小圈微大
- 出现性行为或高强度/侵入/暴露 → 升入 BDSM

## 玩法清单

| 章节 | key | 一句话说明 |
|---|---|---|
| 训诫 | discipline | 定罪、立规矩、说教,责罚前的"讲道理"环节 |
| 打屁股 | spanking | SP 责打:OTK/桌边/床边,板子/皮带/手掌,核心玩法 |
| 管教监督 | supervision | 生活化管教:作息、学习、汇报、打卡、结算 |
| 罚跪 | kneeling | 反省与听训的姿态罚,搓衣板/键盘递增 |
| 挠痒痒 | TK | 玩闹向"酷刑",逼供式嬉闹 |
| 善后安抚 | aftercare | 罚后情绪落地:揉伤、拥抱、复盘、留钩子 |

## 相邻边界

- **与 02-light-plus**:小圈本身无性;一旦剧情进入隔衣挑逗、指奸、口舌刺激等,切换到微大技能。
- **与 03-bdsm**:责打强度升级(破皮见血)、出现性行为、囚禁、暴露时,切换到 BDSM 技能。
- 善后安抚可作为任何大类玩法后的收束章节使用。
