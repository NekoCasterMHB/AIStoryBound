# 肛部玩法 Anal Play

## 何时使用 When to use

- 以"检查/体检/测量"等名义展开的入侵式羞耻玩法时。
- 尾巴装扮、驯服感塑造(夹紧、轻拽提醒)类调教互动时。
- 需要层层铺垫、渐进侵入的慢节奏剧情时。

不要用于:未经润滑与适应的一步到位;任何可能造成伤害的无准备描写。

## 核心原则

1. **名义先行**:每次侵入都有"名目"(检查、测量、佩戴),羞耻感来自名目与身体反应的错位。
2. **润滑与渐进**:涂润、观察、试探、深入各一步,每步都有角色适应反应的描写。
3. **羞耻心理为主**:物理刺激适度,心理层面(被审视、被命令保持姿势)才是刻画重点。
4. **可表态不适**:角色全程能说不、能皱眉、能讨价还价,主导方据此调整节奏。

## 玩法一:肛门检查 anal-exam

### 触发场景

以"检查/体检"为名义的侵入式身体玩法。

### 执行步骤

1. 铺垫姿势与"检查"说辞,营造被审视的羞耻(命令摆好体位、交代检查原因)。
2. 戴手套/涂润滑,先观察再探入,循序渐进,交代每一步的适应。
3. 探入时边检查边评价反应,维持"公事公办"的腔调(报数据、下结论)。
4. 收尾按流程取出、清理,给一句例行评价("恢复得还行"之类)。

### 规则与红线

- 全程有润滑与渐进;用具与深度贴合谨慎描写,让角色始终可表态不适。
- "医生"腔调要克制,不写医疗错误细节,评价以羞耻感服务为主。

## 玩法二:量肛温 anal-temp

### 触发场景

使用体温计等道具做出的羞耻型小玩法(受罚后"检查"、例行惯例)。

### 执行步骤

1. 铺垫"测量"目的与姿势要求,强调羞耻感(趴好、不许乱动)。
2. 涂润、缓慢放置,命令夹住保持,交代寒冷器具的触感。
3. 等待读数期间维持窘态互动(说话/动作被管束,怕读数被报出来)。
4. 取出报数,评价偏高偏低,顺势训话("紧张成这样,体温当然高")。

### 规则与红线

- 道具描写需安全,时间不宜过长;以羞耻心理为主、物理刺激为辅。
- 报数环节要留一句"达标与否"的悬念,给训话接话口。

## 玩法三:肛塞尾巴 tail-plug

### 触发场景

角色佩戴尾巴装扮、被要求展示装扮,或训话进行中围绕尾巴互动。

### 执行步骤

1. 描写尾巴被安置与戴上的过程,捕捉角色的羞耻与紧绷反应。
2. 尾巴随情绪摆动:紧张时夹紧、兴奋时轻摇,作为状态细节反复呈现。
3. 训话中要求夹紧尾巴,违规时轻拽尾巴提醒,并口头强调规矩。
4. 适时让角色对镜观赏自己的装扮,强化羞耻与依赖感。

### 规则与红线

- 佩戴需充分适应与润滑,以羞耻心理为主;不写剧痛或不适到无法承受。
- 摘除时机由支配方决定,摘除本身可作为奖励环节,别变成纯惩罚道具。

## 应用场景示例

### 示例一:术后"复查"(检查名目)

- **设定**:主从同居,角色做了个小手术(虚构),医生角色扮演复查。
- **展开**:先命令摆好复查体位,交代"医生说要做指检" → 戴手套涂润滑,先观察再探入,角色绷紧又被要求放松 → 边查边报"恢复得不错",评价让角色脸红 → 收尾取出清理,医嘱"下个月再来复查"。
- **收尾**:角色嘟囔"复查就复查,别说得像夸我",主导方补一句"下个月还有尾巴项目",把两个玩法串起来。

### 示例二:训话中的尾巴课程(装扮调教)

- **设定**:支配方给角色买了尾巴,今晚开始"尾巴课"。
- **展开**:佩戴时先讲规矩("尾巴是心情的信号,不许装乖")→ 训话中命令夹紧,角色一松懈尾巴就晃,被轻拽提醒 → 逼到镜前自己看,角色捂脸又忍不住偷瞄 → 得到"今天先到这"的许可后,由支配方亲手摘除作为奖励。
- **收尾**:尾巴收进抽屉,角色问"明天还上课吗",得到一个"看表现"的答复。
