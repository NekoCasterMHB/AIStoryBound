# 玩具与敏感刺激 Toys & Sensation Play

## 何时使用 When to use

- 前戏需要拉长节奏、吊着不满足时(挑逗类)。
- 使用口舌或小型道具聚焦敏感点的持续刺激时。
- 道具插入式互动(震动棒等)需要使用分寸与渐进描写时。

不要用于:未经铺垫的突然插入;把道具当成无限大或无底线强度描写。

## 核心原则

1. **由外到内、由轻到重**:每一步都在前一步被接受后再推进,给身体反应留足空间。
2. **"磨人"优先**:挑逗类玩法以"差一点"的节奏制造余韵,不经同意不骤然加码。
3. **反应层次**:描写身体反应(腰弓、腿颤、声线变化)比描写道具本身更重要。
4. **收放有度**:临界点次次收放,高潮可以给,也可以吊着留到下一回合。

## 玩法一:小玩具挑逗 toy-teasing

### 触发场景

用小型道具(跳蛋、软毛、羽毛等)做隔衣或轻触挑逗。

### 执行步骤

1. 从外缘/衣物外开始,轻慢逗弄试探反应。
2. 观察并描述角色的绷紧、躲闪或迎合。
3. 视反应逐步深入,或保持隔靴搔痒的磨人节奏。
4. 转移阵地或收手,留下余韵与期待。

### 规则与红线

- 强度循序渐进;以"磨人"为主,不经同意不骤然加码。
- 隔衣阶段至少 1~2 拍,不要一上来就贴身直击。

## 玩法二:阴蒂吮吸 clitoris-suck

### 触发场景

聚焦敏感点的口舌刺激,需要细腻描写时。

### 执行步骤

1. 从含弄、舔舐过渡到吸吮,节奏由慢到快。
2. 描写吸力变化与反应:腰弓、腿颤、声线变化。
3. 在临界点次次收放,拉长前戏。
4. 高潮或以停下吊着为收尾。

### 规则与红线

- 贴合人物卡敏感度与性欲档位;避免机械复述,注重反应层次。
- 收放节奏要明显(快—慢—快),不要匀速到底。

## 玩法三:震动棒插入 vibrator-insert

### 触发场景

使用震动按摩棒做插入式互动。

### 执行步骤

1. 先以震动棒在体外试探湿滑与适应。
2. 缓缓进入,描写进入过程与体腔内的挤压感。
3. 变速/换档配合需要,变换角度。
4. 高潮或撤出时缓出,注意拔出的体感反差。

### 规则与红线

- 尺寸与深浅贴合人物卡经验设定,不做超出角色的夸张描写。
- 注重扩张不适与快感之间的平衡,不适时给减速/停止的余地。

## 玩法四:AV棒挑逗 wand-teasing

### 触发场景

用魔力棒/AV棒做大面积贴放刺激。

### 执行步骤

1. 先在身体表面滑动、试探最敏感位置。
2. 贴放固定或小幅打转,靠震动档位操控。
3. 反复平移与固定交替,快慢错落。
4. 转移部位或持续推进至高潮。

### 规则与红线

- 贴放部位与档位随反应调整;描写重点放在需要伸手去扶的失控感。
- 大面积刺激强于局部点刺激,档位递进幅度要更小。

## 应用场景示例

### 示例一:睡前"奖励时间"的隔衣挑逗(主从关系)

- **设定**:主从同居,睡前由主导方判断今天的表现配不配奖励。
- **展开**:先给一句"今天还算乖"定调 → 隔着睡裙用跳蛋从腿侧滑到腹下,不掀开 → 角色绷紧躲闪被按住,只得老实躺着 → 档位两下一换,隔衣的震动让角色小声求"掀开" → 主导方以"求人是什么规矩?"要求改口称称谓 → 得到正确称谓后掀开衣角,却把跳蛋移开吊着。
- **收尾**:留下"明天表现好就补上"的约定,角色抱着被挑逗得难受的余韵入睡——正好是下一回合的钩子。

### 示例二:浴室里的"逼供"(口舌 + 道具组合)

- **设定**:支配方怀疑角色藏了事,浴室里一边冲洗一边问。
- **展开**:先用水流做铺垫(淋浴代替道具试探)→ 逼问一句,角色支吾 → 改用口舌刺激,问一句收一分力度 → 角色在临界点上招供细节 → 招完按约定放开,或按约定(招得慢)补一次震动棒缓入的"确认"。
- **收尾**:以"早说不就没事了"收束,湿着头发罚站片刻,再给浴巾。
