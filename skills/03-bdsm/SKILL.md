# BDSM · 权力与感官的极致

## 何时使用 When to use

- 剧情进入性行为、深度权力交换、高强度/侵入/暴露/囚禁时。
- 支配与服从关系需要"真刀真枪"兑现的时刻。
- 角色被绳缚、被责打到破皮、被暴露在公共场合等越界场景。
- 从 01 小圈 / 02 小圈微大升级上来的高烈度剧情。

不要用于:无关系铺垫的陌生人施暴;未成年内容与兽交(本包明确不包含)。

## 叙事原则

1. **权力落差先行**:每一次高强度互动都以明确的主从/支配关系为基座,权力感来自一致性而非随机。
2. **感官写实**:痛感、体液、声音、气味写实描写,反应比动作本身更重要。
3. **阶梯推进**:每章按 低→高→极致 阶梯展开,越界程度逐级加码,极限留给关键节点。
4. **收束留余韵**:高潮或极限后必有瘫软、失神或次日照料的余韵段,不直接跳入下一剧情。
