# 暴露与场景 · 参考文件

本文件为 SKILL.md 的补充参考(安全清单、环境张力、收束流程),不替代 SKILL.md 正文。

## 场景安全清单(开场自检)

| 检查项 | 合格标准 |
|---|---|
| 私密度 | 当前时段/地点可预期无人或极少人 |
| 退场路径 | 有明确"回程"路线与掩护物 |
| 例外预案 | 被人看见时怎么办(借口/离开/收束) |
| 边界声明 | 场景中无真实旁观者参与描写 |

四项全过才展开暴露类剧情;中途"差点被发现"后必须回到安全落点。

## 环境张力描写要点

- **声音**:脚步声、楼道开门声、风声、水声——用环境音代替视线,制造"可能被发现"的紧张。
- **距离**:交代"还有几米到拐角""灯光照到的范围",距离就是张力刻度。
- **光线**:路灯、月光、雾气,亮暗交替控制暴露感。
- **地形**:借力点、掩护物、限制动作的地形(坡道、台阶、窄巷)。

## 暴露类通用收束流程

1. 回到安全点(进门/上车/拉上窗帘)。
2. 松弛描写:瘫坐、长出一口气、后知后觉的腿软。
3. 复盘:主导方点评哪一段"危险"、哪一段"及格"。
4. 预期:一句下次的伏笔,完成闭环。

## 与叙事注入的配合

- 场景类玩法与「成人模式」开关协同:开启时暴露频率可提升,但安全前提永远保留。
- 规则优先级低于 SKILL.md 正文与人物卡;虚构边界(无真实旁观者)始终优先。
