# 暴露与场景 Exposure & Scenarios

## 何时使用 When to use

- 公共/半公共场合的暴露与羞耻剧情(外出露出、裙下机关、危险边缘试探)。
- 浴室/浴缸、户外等场景化的亲密互动。
- 户外场景中的调教任务与服从训练。

不要用于:真实侵害或真实旁观者卷入的描写;一切暴露必须以"无人察觉/可随时退场"为安全前提。

## 核心原则

1. **安全前提先行**:每个场景开场交代私密性(无人经过、可随时退场、有掩护),中途允许"差点被发现"的紧张,但永远回到安全落点。
2. **虚构边界**:只写"仅有彼此"的体验;路人只作为风声、脚步声等环境暗示存在,不写真实参与。
3. **场景即道具**:利用环境本身(水、地形、光线、距离)制造张力,而不是干瘪地套模板。
4. **回程收束**:暴露类玩法结束后要有"安全返回"的松弛与后怕,形成完整闭环。

## 玩法一:外出露出 public-exposure

### 触发场景

在公共/半公共场合维持暴露或羞耻装扮的玩法。

### 执行步骤

1. 铺垫外出理由与伪装(裙摆、开口处、裙下机关),交代风险边界("今天这条街人少")。
2. 写公共场合的克制:绷紧、怕被发现的姿态与心跳,维持正常行走的体面。
3. 危险边缘反复试探(经过人群、被注目、电梯开门),每次"差一点"后回到安全距离。
4. 安全返回后的松弛与后怕,清理与复盘。

### 规则与红线

- 必须包含合理安全前提(无人察觉/可随时退场);不写真实侵犯他人,保持虚构边界。
- "差点被发现"每回合最多 2 次,过多会削弱紧张感并显得不合理。
- 结尾必须有安全落点,不把悬念留在惊险处。

## 玩法二:浴缸做爱 bath-sex

### 触发场景

浴室/浴缸场景的亲密互动。

### 执行步骤

1. 铺垫注水、沐浴、雾气与空间狭小感(水声、蒸汽、贴着瓷砖的凉意)。
2. 湿滑水中的抚摸与水声、浮力带来的姿势限制(滑、坐不稳、需要借力)。
3. 水面上下交替,水花与呼吸节奏,水下的模糊感。
4. 以浴后擦拭、暧昧收尾(浴巾、吹头发、挤在一起)。

### 规则与红线

- 结合水景细节(水声、浮力、滑腻);滑倒等意外可作插曲,但别喧宾夺主。
- 泡浴时间与水温要给角色"热得脸红"的合理反应,不要泡到发晕。

## 玩法三:野外做爱 outdoor-sex

### 触发场景

户外场景的性爱互动。

### 执行步骤

1. 铺垫地点与私密性、被发现的风险(隐蔽的小树林、天台角落、车后座)。
2. 借助地形描写姿势与摩擦(树干、草地、岩石、车座)。
3. 穿插风声、光线、怕暴露的紧张(手捂住嘴、压低呼吸)。
4. 事后整理衣物、检查痕迹,仓皇或满足地收束。

### 规则与红线

- 地点必须私密可行,维持"仅有彼此"的边界,不做真实旁观者描写。

## 玩法四:野外调教 outdoor-training

### 触发场景

户外场景中的调教玩法(命令、服从、暴露训练)。

### 执行步骤

1. 选定半隐蔽场地,交代规则与口令(在哪个区域、听什么指令)。
2. 布置服从任务(固定姿态、等待、夹紧等)并监督,借地形限制行动。
3. 用周围环境(路人声、风声)制造紧张与羞耻,穿插口令验证。
4. 终结时收束回安全点,总结表现与奖惩("今天勉强及格")。

### 规则与红线

- 以"在场无人察觉"为安全前提;命令不超人物卡身份与耐受尺度。
- 任务可含暴露元素,但距离与掩护始终在场,不做真正的公共曝光描写。

## 应用场景示例

### 示例一:深夜便利店路口的外出露出(主从关系,首次露出)

- **设定**:主从同居,主导方决定给角色一次"外出的练习",路线选在深夜人少的街区。
- **展开**:出门前交代伪装(短裙+外套,只能解开外套两颗扣)与红线(一路不许回头) → 路上每经过一盏路灯都绷紧,心跳声自己听得见 → 便利店门口差点被夜班店员看见,借口买水快步离开 → 安全回楼道后瘫在门上,外套早在电梯里就被迫解开。
- **收尾**:进门后主导方先复盘("哪一段差点露馅"),再给一句"下周换个地方练"的预期,留钩子。

### 示例二:温泉小旅馆的浴缸(关系升温向)

- **设定**:两人短途旅行,订了带浴缸的房间,关系从管教向暧昧递进。
- **展开**:放水时互相调侃"这缸够两个人吗" → 泡入后水声盖住心跳,浮力让角色坐不稳只能靠过去 → 水面上下交替,雾气里的对视比动作更暧昧 → 换水加温时互相泼水打闹,回到"日常调情"的层次。
- **收尾**:浴后裹着浴巾互相吹头发,以一句"明天换个更大的缸"收束。

### 示例三:天台角落的"站桩训练"(野外调教)

- **设定**:公寓天台,夜晚无人,主导方训练角色的服从与暴露耐受。
- **展开**:定下口令("站到我说停为止")与区域(排水管旁阴影内) → 布置任务:保持姿势、风来时不许缩 → 远处传来邻居开门声,角色僵住,主导方用一句口令稳住 → 任务结束回屋,复盘时指出"你刚才差点犯规"→ 奖惩:及格,免去加训。
- **收尾**:以"下次训练看天气"带过,留下对下一场的期待与畏惧。
