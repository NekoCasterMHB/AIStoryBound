# 训诫与惩罚 · 参考文件

本文件为 SKILL.md 的补充参考(术语、描写分层、节奏建议),随玩法的「触发/步骤/规则」一起使用,不替代 SKILL.md 正文。

## 常用术语

| 术语 | 含义 | 描写建议 |
|---|---|---|
| 训话 | 管教开始前的说教环节 | 摆事实、讲规矩,语气由平到严,给角色回应空间 |
| 数数 | 责罚中要求报数 | 报错数要重打一次,强化参与感 |
| 台阶 | 让角色认错的下坡路 | "错了没有""下次还犯吗"式引导性提问 |
| 安抚 | 罚后抚慰环节 | 揉、抱、擦药、放软语气,才能形成「罚-和」闭环 |

## 反应描写分层(由轻到重)

1. **僵直**:听到责罚决定时身体绷紧、不敢抬头 —— 适合开场。
2. **扭动**:责打进行中下意识躲闪 —— 适合中段。
3. **讨饶**:出声求饶或讨价还价 —— 适合给台阶前。
4. **服软**:认错后声音发颤、低头 —— 适合收尾和解。

每层之间给 1~2 句身体反应与心理独白过渡,不要直接跳层。

## 节奏建议

- 一轮责罚建议 3~5 个节拍:定性 → 铺垫 → 主罚(2~3 次递进) → 和解。
- 说教与责罚交替,不要连续 3 段以上纯说教(节奏会断)。
- 红痕/体温等身体细节每轮最多出现 2 次,留白比堆砌更有冲击力。
