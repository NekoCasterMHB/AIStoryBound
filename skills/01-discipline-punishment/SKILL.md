# 训诫与惩罚 Discipline & Punishment

## 何时使用 When to use

- 角色违反明确立过的规矩、顶嘴、隐瞒或迟到等过错需要被追究时。
- 主从 / 师生 / 长辈与晚辈等存在管教关系的互动中,需要重申规矩与权威时。
- 玩家主动引导管教向惩罚剧情(责打、说教、注射惩罚)时。

不要用于:平级无管教关系的人物之间凭空施加责罚;连续多回合单方面虐待式描写(需要给认错与和解的出口)。

## 核心原则

1. **先立过错,再定责罚**:每一轮责罚都从"具体过错 + 因由"开始,不营造无理由的暴力。
2. **分档推进**:责罚强度、下数、说教语气随人物卡性欲档位与关系设定调整;未受过责罚的角色从试探性开始。
3. **全程可喊停**:被责罚方必须能中途求饶、讨价还价或喊停,互动在可协商的空间内进行。
4. **以和解收尾**:认错 → 安抚/抚慰 → 明确改过预期,形成闭环,不写给情绪失控的贬损。

## 玩法一:打屁股 spanking

### 触发场景

训话/管教场景,或角色因违反规矩明确受罚。

### 执行步骤

1. 铺陈姿势与心态:被按在膝上或桌边,衣物半褪,露臀拘谨等待,交代此刻的羞耻与紧张。
2. 责打由慢到快、由轻到重,穿插数数、说教与身体反应(红痕、扭动、讨饶)。
3. 按惩罚进展逐步升级节拍与力度,在角色求饶时给台阶,让认错有分量。
4. 收尾以安抚或继续训话结束,明确"这次记住了"。

### 规则与红线

- 力度与下数随人物卡性欲档位与关系设定把握;每 10~20 下应给一次缓歇。
- 被打者必须能中途开口求饶或喊停,不写成完全麻木或失语。
- 红痕描写以"泛红、发烫"为上限,不写破皮出血。

## 玩法二:训诫 discipline

### 触发场景

角色违反规矩、顶嘴或需要重申规则时。

### 执行步骤

1. 抓住具体过错,逐条复述因由,让角色无话可辩。
2. 定下规矩与惩罚档位,要求角色复述确认。
3. 执行责罚(言语说教 + 适度肢体),一边说教一边强化规矩的重要性。
4. 认错后给安抚与和解,明确此后改过的预期,给台阶下。

### 规则与红线

- 说教内容贴合人物卡关系(师生/主从/长辈)设定,不越出身份语境。
- 不做羞辱人格的贬低(如外貌、智力攻击);训诫的目的是"规矩",不是"贬损"。
- 说教时长与责罚强度成比例,避免长篇空谈打断节奏。

## 玩法三:打屁股针 spank-needle

### 触发场景

以"打针"为名的惩罚/羞耻向玩法(医嘱、犯错后处置等)。

### 执行步骤

1. 铺垫医嘱/惩罚原因,命令裤袜半褪露出臀位,交代紧张感。
2. 描写碘伏消毒、拍打肌肉放松、针尖贴皮的短暂僵持。
3. 注入时配合说教与安抚,描写绷紧与呼痛,节奏与语气并进。
4. 推注完成、按压棉签,收尾叮嘱以后守规矩,给一句"下次别让我再打针"式的预期。

### 规则与红线

- 只做表现性描写(消毒/贴皮/注入/按压),不细写医学操作步骤以免错漏。
- 分寸随人物卡掌握;角色可以怕针、躲针,但最终由主导方安抚完成。
- 注射部位描写限定于臀部常规区域。

## 应用场景示例

### 示例一:迟归的惩罚(主从关系,新仆从第一次受罚)

- **设定**:主从同居关系,规矩是"十点前到家,晚归要提前报备"。角色九点半未回、十点半才进门且没发消息。
- **展开**:主导方不问缘由先让角色复述规矩(训诫)→ 查出是去逛街忘了看时间(定性过错)→ 按在膝上打屁股,先轻后重,数到二十下时问"错了没有" → 角色讨饶认错、保证下次报备 → 罚后揉臀安抚,复述新约定。
- **收尾**:以一句"记住今晚的数"结束,给角色留下下次犯错会被加罚的预期。

### 示例二:护理室的一针(角色扮演向)

- **设定**:医护/病号扮演,角色感冒仍偷吃冰淇淋被"医嘱"打针。
- **展开**:先是诊断与说教(训诫)→ 命令趴在床边褪裤,消毒时角色紧张到绷紧 → 拍打让肌肉放松,针尖贴皮时讨价还价"能不能轻点" → 注入时轻呼,主导方嘴上说教手上不停 → 棉签按压收尾,叮嘱忌口。
- **收尾**:角色赌气说"再也不吃冰淇淋了",主导方补一句"下次再犯就换大一号针头",留个羞耻把柄。
