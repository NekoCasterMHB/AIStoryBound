# 公共play · 04-pubplay 玩法说明

## 类定义

公共play 是"在公共/半公共场所里维持表面正常、暗处推进成人互动"的玩法体系：核心张力来自**四件事**（衣服没脱光、动作要藏得住、随时可能被打断、双方还演着"在做别的事"），以及"被看见、被掌控"的遮掩感——而非真的暴露给旁观者。所有参与者均为成年的合意者。

## 判定标准

- 剧情发生在公共/半公共场所（影厅、餐厅、试衣间、办公室、电梯、车内、衣帽间、聚会边角、家中模拟公共等）且有成人互动 → 本技能。
- 出现"让不知情真人亲眼目睹"的苗头 → 立即收束转场，不适用本技能。
- 三人及以上 → 仅限遥控接力，且必须注明均为成年合意参与者。

## 玩法素材（全部条目见 SKILL.md 正文，逐字来源）

SKILL.md 正文包含四大块素材库，AI 注入时按剧情取用：

1. **强度递进**：轻度挑逗 → 隐秘刺激 → 半公开前戏 → 高强度性爱 → 高潮控制（五档，按一处场景选一档为主线）。
2. **场景模块**：八大公共/半公共舞台（私人影厅、餐厅包厢与桌下、试衣间、办公室/档案室、包场电梯、静止车辆、衣帽间、家中模拟公共），每次只取一个。
3. **可叠加玩法**：衣着/道具/姿势/声音/暴露 五类限制，一次取 1–2 款与主玩法组合。
4. **高刺激玩法库**：一组进阶素材（遥控、静止、称谓、没收、接听、余韵、藏匿、扮演、接力、逐关），一次取 1–2 个带动主玩法。

## 相邻边界

- **与 01-light**：日常生活化暧昧、不明场合办公室戏 → 小圈；一旦进入公共场合的明示身体互动 → 本包。
- **与 03-bdsm**：真权力交换、挣扎束缚、击打等 → BDSM；本包专责"场合遮掩 + 维持表面正常"的张力。
- 本包强调"场所先行"：场所决定玩法边界，而不是玩法决定场所。

## AI 注入提示

- 开篇用两句话营造"表面正常"（在做什么事、说什么话），再进入暗处细节。
- 每个场景安排一次"打断/倒计时"的钩子（电话、敲门、上菜、车灯），未必真发生，但要悬着。
- 结束必须"收容"：原位、正常说话、若无其事，让"没人知道刚才发生了什么"的余韵成立。
- 任何真实旁观者将要目睹的苗头 → 立刻收束转场，不做暴露叙述。
