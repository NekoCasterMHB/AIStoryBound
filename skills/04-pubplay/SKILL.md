# 公共play · 场合里的隐秘张力

## 何时使用 When to use

- 剧情发生在公共/半公共场所（影厅、餐厅包厢/桌下、试衣间、办公室/档案室、电梯/走廊、车内/车库、衣帽间、聚会边角、家中模拟公共）且当事双方为成年的合意者时。
- 需要在"维持表面正常"的同时推进成人互动：一边看电影/吃饭/办公/接电话，一边在暗处升级。
- 需要利用"随时可能被打断、被看见"的压力制造张力与心慌的场合。
- 从 01 小圈 / 02 微大升级上来，或与 03 BDSM 的暴露章节衔接的公共向剧情。

不要用于：把不知情的真实旁观者卷入；未成年内容；真实公共场所实施（本包仅用于虚构叙事）。

## 叙事原则

1. **四件事是基准**：衣服没有完全脱；动作必须藏住；随时可能被打断；双方还要维持表面正常。
2. **场所必须实际影响玩法**，但不需要长篇描写环境。
3. **每次只组合一套**：一个场所＋一种衣着限制＋一至两个主要玩法＋一个控制要求＋一次打断或倒计时＋一种结局；不要把所有姿势、道具和高潮一次塞完。
4. **场所决定边界**：一个场所里能做什么、幅度多大，由"这个场所藏不藏得住"决定。

## 正文（玩法素材库，逐字来源）


【核心玩法】
公共场合性爱的刺激来自四件事：衣服没有完全脱、动作必须藏住、随时可能被打断、双方还要维持表面正常。场所必须实际影响玩法，但不需要长篇描写环境。
每次只组合：一个场所＋一种衣着限制＋一至两个主要玩法＋一个控制要求＋一次打断或倒计时＋一种结局。不要把所有姿势、道具和高潮一次塞完。
【强度递进】
轻度挑逗：暗号、贴耳命令、隔着衣服摸腿根或胸、桌下勾腿、从背后贴住、短暂接吻、故意整理衣服时触碰敏感处。
隐秘刺激：衣服下面手淫或指奸、隔着内裤揉弄、腿间摩擦、坐在腿上磨蹭、遥控跳蛋或震动器、在遮挡下玩乳头。角色仍需保持正常坐姿、说话或完成眼前任务。
半公开前戏：在受控隔间内口交、跪舔、手口并用、镜前展示、掀裙或解开裤链后继续保留大部分衣物。可以加入不许遮、不许夹腿、不许出声、不许自己碰等简单规则。
高强度性爱：只在包场、清场、私人隔间、静止车辆等受控环境中进行站立插入、桌沿性爱、坐姿骑乘、后入或抱操。空间越小，动作越短、越贴身。
高潮控制：可以允许隐秘高潮，也可以故意寸止、在即将高潮时停下、带着跳蛋继续完成任务，或把人带回私密处再给。
【场景模块】
私人影厅／包厢座位：外套遮挡、摸腿、指奸、手交、遥控跳蛋、坐腿磨蹭；核心是必须面朝前方，不能明显扭动。
餐厅包厢／桌下：脚蹭腿根、手伸进裙底、遥控玩具、边正常聊天边控制高潮；适合低调挑逗，不适合大幅性交。
受控试衣间／化妆间：换衣检查、镜前展示、玩乳头、指奸、口交、站立后入；衣服只拨开必要部分，随时可以重新整理。
私人办公室／清场档案室：桌下口交、坐桌沿、趴桌后入、边处理文件边被玩、电话或敲门造成暂停；可突出上下级、工作命令与性命令的重叠。
包场电梯布景／封闭走廊：压墙亲吻、掀裙摸弄、站立插入、抱住磨蹭；适合短促、强压迫的玩法，不适合漫长全套流程。
静止车辆／私人停车场：后座指奸或口交、跨坐骑乘、趴扶座椅后入、外套遮挡、车灯或提示音造成停顿；车辆必须静止。
私人派对边缘／关闭衣帽间：隔着礼服玩弄、摘下内裤留作战利品、短暂口交或快速性交，再整理好衣服若无其事地回去。
家中模拟公共场景：用餐桌、阳台门、玄关、书房、投影影厅或角色扮演布景制造公共感；适合想要完整露骨玩法但不引入真实旁观者的场景。
【可叠加玩法】
衣着限制：短裙、开衩裙、丝袜、连体衣、宽大外套、衬衫、礼服、制服；可设定真空、只脱内裤、扣子只解一半或下身被拨开但上身仍穿整齐。
道具控制：遥控跳蛋、震动内裤、乳夹、肛塞、项圈、腿带、小型震动棒。一次优先使用一种主道具，避免道具展览。
姿势控制：手放桌面、面朝前方、双腿保持指定角度、坐在腿上不许主动磨、被插入后保持静止、有人靠近时含着或夹着不准动。
声音控制：不许叫、只能贴耳说需求、用正常谈话掩饰呼吸变化；成功忍住可奖励，故意出声可暂停刺激或延迟高潮。
暴露控制：掀到什么位置、能不能遮、是否面对镜子、是否保留内裤或让湿痕藏在衣服下。羞耻来自伴侣看见和掌控，不让不知情者实际围观。
任务控制：继续看电影、吃饭、读文件、挑衣服、接电话或等待倒计时；完成任务才升级刺激，走神或犯规则停下。
主导交换：不固定由男性或插入方掌控；可以由穿戴遥控玩具的人反过来命令持遥控者，也可在同一场景中因挑衅、犯规或抢走遥控器短暂易权。
【高刺激玩法库】
遥控耐受：出门前戴好跳蛋、震动内裤或肛塞，主导者只在点单、读文件、与人正常说话等任务中改变档位；完成一项才获得一次短暂释放，直到指定时刻才准高潮。
静止含住：在受控包厢或隔间中把手指、玩具或阴茎放进身体，却不立刻抽动；外面出现声音时必须保持含住和夹紧，等主导者重新下令才恢复动作。
双线刺激：衣服下同时佩戴乳夹与跳蛋、肛塞与震动器，或由手指刺激阴蒂、玩具留在穴内。两条刺激线交替增强，不要一开始全部开满。
内裤没收：进入场所后由主导者亲手脱下并收走内裤，承受者必须穿着裙子、丝袜或礼服继续原本活动；离场、完成任务或坦白身体状态后才决定是否归还。
接听挑战：正在被指奸、口交、骑乘或静止插入时接起一通预设的普通电话，回答指定问题并维持正常语气；说错、停顿或泄露声音便暂停快感、降低档位或重新开始任务。
高潮后续：允许在衣物遮挡下高潮，但不立刻取出玩具或结束触碰，而是维持低档刺激、夹着插入物完成下一段任务，让余韵和过度敏感继续累积。
体液藏匿：在受控场景中让爱液、精液或口水只留在内裤、丝袜、腿根或身体内部，简单整理外观后继续保持体面；不得污染公共物品，也不让旁人实际看到。
陌生人扮演：双方分开入场，假装互不认识，由搭讪、递暗号、桌下触碰逐渐升级，再进入预约隔间；熟悉伴侣利用“不能叫出亲昵称呼”的规则制造反差。
遥控接力：三人及以上均为成年合意参与者时，可在私人包厢中轮流持有遥控器，佩戴者不知道当前由谁控制；每次换手同时更换任务、档位或高潮权限，不让无关旁人参与。
连续闯关：同一晚设置两至三个受控地点，每处只完成一项玩法，例如餐桌下遥控、试衣间检查、静止车辆内高潮；前一处留下的玩具、湿意、寸止或命令带入下一处，最后才决定是否完整性交。

## 组合 & 生成框架

每次生成一段剧情，且只用一个组合：

```
【场景】一个场所（从上面"场景模块"选一个，不叠加）
【衣着限制】一种（从"可叠加玩法·衣着限制"选）
【主要玩法】一至两个（取"强度递进"一档 ＋ 高刺激玩法库取 0–2）
【控制要求】一条（声音／姿势／道具任选一）
【打断／倒计时】一次真实事件或时限（电话、敲门、上菜、车灯……）
【结局】高潮给在露还是不露处，最后一步如何
```

**一句话要求（可置于 Prompt 顶部）**：公共play 的刺激来自——衣服没脱光、动作要藏得住、随时可能被打断、双方还演着"目前在做别的事"；每一段只推进一个场所、一套组合，不把所有姿势、玩具、高潮一次性塞进同一段。若剧中出现真实旁观者将要洞察的苗头，立刻收束转场，不让不知情的真人真正目睹。
