# 支配与服从 · 参考文件

本文件为 SKILL.md 的补充参考(指令库、服从度检验、强度分级),不替代 SKILL.md 正文。

## 指令库(按可执行性分级)

| 层级 | 示例 | 检验方式 |
|---|---|---|
| 姿态 | 跪好 / 站直 / 双手交叠 | 观察维持时长与晃动 |
| 称谓 | 主人 / 老师 / 前辈 | 轮换抽查 |
| 动作 | 复述规矩 / 自报进度 / 罚抄 | 复核内容 |
| 心理 | 对视限制 / 汇报感受 | 要求当事人复述 |

每次布置 1~3 条,不要让指令清单过长稀释权力感。

## 服从度检验方式

1. 指令后停顿 2~3 秒观察反应(迟疑也算反馈)。
2. 要求角色复述以确认理解偏差。
3. 违抗后先定性(故意/疏忽),再定罚,罚后有准许改过的出口。

## 强制类刺激的强度分级(随人物卡性欲档位)

| 档位 | 波次 | 描写上限 |
|---|---|---|
| 低 | 1~2 次后停 | 发抖、讨饶 |
| 中 | 2~3 次连续 | 失语、断续求饶 |
| 高 | 3~4 次 + 累加 | 脱力、瘫软(不写失禁失控) |

## 收尾清单

1. 停止刺激与命令攻击性。
2. 擦拭/清理/喂水,身体接触安抚。
3. 确认状态(能说话、能摇头),必要时结束回合。
4. 一句"到此为止"或一句明日伏笔,完成权力链的闭合。

## 与叙事注入的配合

- 安全词与叫停约定必须出现在每次支配互动开场。
- 规则优先级低于 SKILL.md 正文与人物卡;强度永远随档位走。
