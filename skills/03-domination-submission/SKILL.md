# 支配与服从 Domination & Submission

## 何时使用 When to use

- 主从/支配向互动中,需要"命令-执行-奖惩"的权力链时。
- 角色需要被测试服从度(姿态、称谓、动作指令)时。
- 强制类调教(禁止停下、反复刺激)剧情推进时。

不要用于:无明确关系铺垫的陌生支配;剥夺角色全部自主权的单向剧情(必须保留可表态空间)。

## 核心原则

1. **前置契约**:每次支配互动开始,明确此刻的支配-服从关系与叫停方式(安全词/手势/口头约定)。
2. **指令可执行**:布置的命令必须具体、可检验(姿势、称谓、动作),并让角色复述确认。
3. **奖惩对称**:服从得到奖励,违抗得到惩罚,落差感来自一致性而非随机。
4. **回归平等**:结束时离开支配角色,确认对方的身体与情绪状态。

## 玩法一:SM 权力游戏 sm

### 触发场景

主从/支配向互动,涉及服从测试、命令与惩罚链的权力游戏。

### 执行步骤

1. 明确双方此刻的支配-服从关系与叫停方式,一句话定调。
2. 布置指令并检验执行(命令身体姿态、称谓、动作),不合格重来。
3. 对完成/违抗给予相应奖惩,维持权力落差感(奖:抚慰/放过;罚:加练/责罚)。
4. 结束时回归平等对话,确认状态与情绪,给一句"今晚到此为止"式收束。

### 规则与红线

- 尊重叫停信号,点到即止;服从要求不超过人物卡设定与角色身份的默认尺度。
- 称谓与命令贴合人物卡关系(主人/老师/前辈),不强行套主奴称谓。
- 惩罚链要有边界:每次违抗后给复述规矩的机会,不形成无限加罚。

## 玩法二:强制高潮 forced-orgasm

### 触发场景

角色被禁止停下的高刺激反复调教(支配方掌控节奏的持续刺激)。

### 执行步骤

1. 持续不同方式的刺激使其越过舒适阈值,铺垫"不许停"的命令。
2. 高潮来临时不停止,继续维持刺激过渡到下一次,描写失控、求饶与失语。
3. 连续多波后给喘息或轻微减弱,形成累加感与疲惫。
4. 结束以瘫软与脱力收束,事后安抚与清理,确认状态。

### 规则与红线

- 次数与强度随人物卡性欲档位调整;保留可喊停或弱化的空间。
- 不写成完全失禁失控;角色要能断续表达"不行了"之类的信号。
- 结束后必须有缓和段(擦拭、喂水、搂住),不直接跳入下一剧情。

## 应用场景示例

### 示例一:命令与奖惩链(确立称谓)

- **设定**:主从同居,角色今天擅自叫了主人的名字。
- **展开**:先定约("再听见一次,今晚的份就翻倍")→ 命令角色跪好复述规矩,叫对一次口头表扬 → 中途故意再叫错一次,被抓包 → 按约加罚(责罚 + 强制坐享之后的部分)→ 结束时角色软声保证,以一声正确的称谓收尾。
- **收尾**:主导方给一句"名字留到明天再说",把权力感的余味留到下一回合。

### 示例二:不许停下的夜晚(强制持续刺激)

- **设定**:支配方决定今晚"没有停下的批准权",角色须自己撑到被允许。
- **展开**:开场的命令与叫停约定 → 刺激渐进越过阈值,第一波来临时角色请求停,被驳回("再一回就好")→ 第二波、第三波之间只剩断续的求饶与喘息 → 临近极限时给予收尾许可 → 瘫软后的擦拭与喂水。
- **收尾**:角色蜷着说"再也不逞强了",作为下次再签"今晚契约"的伏笔。
