# NTR多人 · 展示、露出与轻NTR

## 何时使用 When to use

- 剧情进入展示、露出，或"主伴侣＋合意第三人"的多人互动（试衣间、包厢、办公室、影院包间、车内、派对、私人展示房等）时。
- 想要保留一条"主位锚点"的占有张力：第三人只得到被允许的一小部分观看与触碰，最终决定权始终回到主伴侣。
- 从 01 / 02 / 03 / 04 升级上来，展示向剧情、暴露与遥控玩法衔接。

不要用于：未成年内容；把不知情真实旁观者卷入；非合意对象；贬低关系价值的叙事。

## 叙事原则

1. **展示分级推进**：只给伴侣看 → 合意旁观 → 调情与限触 → 有限借用，可逐级推进，可停在任一级。
2. **保留主位锚点**：遥控器、项圈、停止信号、高潮许可与最终回收权始终在主伴侣手中；第三人只是被允许的观众与有限接触者。
3. **打断只需一次**：脚步、广播、电话、门外人声、灯光变化或倒计时，出现即暂停，压力过后再决定继续或终止。
4. **每次只组合一个框架**：一个场所＋一种展示强度＋一至两个主玩法＋一个打断/倒计时＋一种结局。

## 正文（玩法素材库，逐字来源）

【展示、露出与轻NTR】

展示强度分四级，可逐级推进，也可停在任一级：

1. 只给伴侣看：在镜前、帘后、桌下或半开的外套里按命令露出乳房、内裤、臀腿或私处；刺激来自外面可能有人经过，但实际只有伴侣看清。
2. 合意旁观：受邀第三人可以看见指定部位、看主伴侣亲手脱衣或玩弄身体、听见命令与反馈，但不得触碰。可加入打分、夸奖、描述身体反应或与主伴侣进行占有欲对话。
3. 调情与限触：第三人可以搭讪、赞美、共舞、贴近耳语、摸腰腿、隔着衣料揉捏或短暂亲吻；主伴侣握着遥控器、规定手能放在哪里，并观察伴侣是否因别人接近而变湿、勃起或失态。
4. 有限借用：主伴侣明确划定一段时间和一项动作，允许第三人手淫、指奸、玩乳头或进行短暂口交，但不允许完整性交，也不把高潮决定权交给第三人。超过这一档便切换多人性爱规则。
可直接调用以下玩法：
- 借看不借碰：主伴侣把衣物拨开、摆好姿势，让第三人近距离看或评价；第三人越想碰，越被要求把手放好。
- 遥控约会：伴侣与第三人假装约会、喝酒或聊天，主伴侣坐在附近或远程控制体内玩具；第三人的每次示好都会换来一次档位变化。
- 限时借用：主伴侣准许第三人获得三条命令、三分钟触碰或一次亲吻，时间一到立即收回；第三人只能在授权范围内选择怎样使用机会。
- 当面比较：第三人触碰或挑逗时，主伴侣要求伴侣看着自己，汇报哪里被碰、身体有什么反应、谁更了解敏感点。比较用于激起嫉妒和占有，不贬低关系价值。
- 假装陌生：两位伴侣分开入场，其中一人与合意第三人搭讪、调情或接受触碰，另一人装作不认识却全程观察；只有暗号、遥控器或目光暴露真正关系。
- 展品姿势：在私人展示房、角色扮演派对或合意观众面前保持指定姿势，由主伴侣决定露出多少、是否允许转身、张腿、抬裙或面对镜子。
- 回收验收：展示结束后，主伴侣把人重新抱回身边，检查第三人碰过的地方、追问每次反应、重新施加玩具或亲自让其高潮；嫉妒最终转化为更强的占有与偏爱。
NTR必须保留一条清晰的“主位锚点”：主伴侣持有遥控器、项圈牵引、停止暗号、高潮许可或最后的回收权。第三人得到的是被允许的一小部分观看与触碰，不取代核心关系。
【打断玩法】
打断只需出现一次：脚步靠近、广播响起、电话接通、门外有人说话、灯光变化或倒计时结束。出现后立即暂停、维持原姿势或恢复表面正常，等压力过去再选择继续、加重、寸止或离场。

【组合示例】

- 受控试衣间＋内裤没收＋镜前玩穴后塞入跳蛋＋穿好新裙继续闯关＋回到车内才完成性交。
- 清场办公室＋桌下口交＋电话接通时静止含住＋通话结束后转为桌沿后入＋高潮后继续夹着不许立刻整理。
- 私人派对＋三位成年合意参与者遥控接力＋佩戴者维持正常社交＋衣帽间内确认是谁控制＋最终奖励由胜者决定。
- 私人展示房＋短裙真空＋主伴侣亲手掀裙展示＋合意第三人只能看和评价＋结束后由主伴侣当面玩到高潮。
- 受控试衣间＋主伴侣与合意“店员”角色＋镜前换裙和内裤没收＋第三人只准整理丝袜、摸腰腿和亲吻＋超时立即收回。
- 私人包厢＋限时借用三分钟＋第三人获得指奸或口交二选一＋伴侣全程看着主伴侣汇报感受＋高潮必须留给主人。

## 组合 & 生成框架

每次生成一段剧情，只用一个组合，推荐输出骨架：

```
【场景】一个场所（不叠加）
【展示强度】四级中取一级作为主线
【主玩法】一至两个，注明由谁执行
【主位锚点】必须写一条：遥控器/项圈/停止信号/许可/回收权，在哪、如何体现
【控制要求】一条：第三人被允许什么、被禁止什么
【打断/倒计时】一次真实事件或时限
【结局】回收验收、回到主位、怎么收束
```

**生成底线**：NTR 必须保留"主位锚点"贯穿全段；一切展示、触碰、借用只存在于合意的多人之间；第三人得到的始终是允许的一小部分
