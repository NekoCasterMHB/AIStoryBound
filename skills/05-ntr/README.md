# NTR多人 · 05-ntr 玩法说明

## 类定义

NTR多人play（展示、露出与轻NTR）是"主伴侣＋合意第三人"在场、以展示/露出为核心张力的玩法体系：刺激来自"被看见、被比较、被短暂借用"，但有一条永远不动摇的**主位锚点**——主伴侣持有遥控器、项圈牵引、停止暗号、高潮许可或最后的回收权；第三人得到的是被允许的一小部分观看与触碰，不取代核心关系。所有参与者均为成年合意者。

## 判定标准

- 剧情涉及展示、露出、或第三人（合意旁观者/被限触者）在场参与 → 本技能。
- 第三人触碰与否、触碰多少、借多久，全部由主伴侣授权并计时；越界/超时立即收回。
- 出现完整性交或真正的多人性爱 → 超出本包范围（本包上限是"有限借用"一档）。
- 任何把不知情真实旁观者卷入的安排 → 立即降级或收束，不进入暴露给真人的叙事。

## 玩法素材（全部条目见 SKILL.md 正文，逐字来源）

SKILL.md 正文含四组素材，AI 注入时按剧情取用：

1. **展示强度（四级）**：只给伴侣看 → 合意旁观 → 调情与限触 → 有限借用；可逐级推进，也可停在任一级。
2. **可直接调用的玩法**：借看不碰、遥控约会、限时借用、当面比较、假装陌生、展品姿势、回收验收（每一条描述与授权边界见正文）。
3. **打断玩法**：只出现一次（脚步、广播、电话、门外人声、灯光变化或倒计终），出现即暂停或恢复表面正常。
4. **组合示例**：六条参考组合（试衣间、办公室、私人派对、私人展示房等的具体串联）。

## 相邻边界

- **与 01-light**：无第三者的日常暧昧/责打/管教 → 小圈；一旦引入合意第三人或展示 → 本包。
- **与 04-pubplay**：公共场合性爱侧重"场合遮掩 + 维持表面正常"；本包侧重"第三人观看/被允许的接触"。
- **与 03-bdsm**：BDSM 的工具性控制（绳、打、项圈彻底役属） → 03；本包用"主位锚点"做轻量占有，不进入重度行为。
- 若剧情走向真多人性爱（超越"有限借用"档） → 由多人规则接管，本包止步。

## AI 注入提示

- 生成开篇两句话维持"表面正常"（正在做一件普通的事），再进入展示/借用细节。
- 每次展示、触碰、借用都写清**授权项**（谁做什么、做多久、什么时候收回），让"主位锚点"每句都立得住。
- 打断只发生一次即可；结束后要有"回收验收"或"回到主位"的收束动作。
- 一切"被允许"都来自在场的成年合意者；真实旁观者不被卷入，也不进入非自愿叙事。
