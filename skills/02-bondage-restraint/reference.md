# 束缚与限制 · 参考文件

本文件为 SKILL.md 的补充参考(缚法用语、反应分层、松绑流程),不替代 SKILL.md 正文。

## 缚法用语

| 术语 | 含义 | 描写建议 |
|---|---|---|
| 锁腕 | 手腕交叠后缚住 | 先"交出手腕"再"绕两圈收紧",给角色选择权 |
| 余量 | 绑缚后手指能动的空间 | 每次缚完交代一句,让读感安全 |
| 绳痕 | 解绑后留下的印子 | 用"泛红""压痕"描写,不写破皮 |
| 背手 | 双手背后交叉的缚位 | 适合站姿听训,与责罚体位衔接 |

## 被缚反应描写分层

1. **试探**:拉两下、转手腕,确认余量 —— 刚绑上时。
2. **受限**:想动动不了,动作幅度收窄 —— 中段。
3. **妥协**:放弃挣扎,改成口头请求 —— 推进其他玩法前。
4. **依赖**:被缚中反而放松/安心 —— 关系深入的角色的收尾层。

每层之间给 1~2 句身体细节,不要瞬间从"挣扎"跳到"顺从"。

## 松绑流程清单

1. 按缚序倒序松结(先外后内)。
2. 检查绳痕/压痕,揉按回血。
3. 一句安抚或一句预期,明确"被缚状态已结束"。
4. (可选)留一句下次的伏笔。
