# 束缚与限制 Bondage & Restraint

## 何时使用 When to use

- 支配互动中需要限制角色行动(捆绑、缚手、锁住)时。
- 剧情需要"被困住却逃不开"的张力:夜话训话、责罚前置、玩具配合。
- 角色被缚后仍要推进其他玩法(责罚、玩具、盘问)时。

不要用于:真实伤害向描写;颈部环绕等危险勒束;长期囚禁类剧情(单回合内的被缚状态即可)。

## 核心原则

1. **松紧透明**:每一处缚法都交代松紧与可活动余量,角色能轻微活动、能表达不适。
2. **绳感优先**:被缚者的体验(勒痕、摩擦、无力感)比绳结本身更重要,多写身体反应。
3. **保留出口**:始终留有"随时可解"的表述空间与喊停通道。
4. **按序解缚**:结束时按绳结顺序松绑,处理酸麻与勒痕,给安抚。

## 玩法一:捆绑 bondage

### 触发场景

涉及限制行动、绑缚的支配互动(责罚前置、夜训、玩具配合等)。

### 执行步骤

1. 描写绕绳与打结过程,交代每一处的松紧与可活动余量(手腕、臂弯、必要时脚踝)。
2. 强调被缚者的试探性挣扎与绳感(勒痕、摩擦、挣脱不动的无力感)。
3. 捆绑后按支配节奏推进其他玩法,或单纯维持被困状态制造张力。
4. 结束时按绳结顺序松绑,处理酸麻与勒痕,收尾安抚。

### 规则与红线

- 不描写会导致呼吸困难的颈部环绕勒束;肩部以上只做装饰性绳结。
- 松紧随人物卡耐受度调整,留出喊停余地;不写勒到发麻变色的程度。
- 被缚后角色可以口头抗议、悄悄挪动,保持活性而不是木偶。

## 玩法二:皮带捆手 belt-hands

### 触发场景

用皮带束缚双手的支配玩法(训话时要求交出手腕、责罚前置等)。

### 执行步骤

1. 让角色交出手腕,描写皮带穿扣与收紧的过程,交代松紧感受。
2. 强调双手被缚后的无力感与身体可控性(想护臀却护不到等细节)。
3. 借缚手状态引导后续动作或玩法(跪好、听训、接受责罚)。
4. 解缚时检查压痕并安抚,收尾交代"下次还敢吗"式预期。

### 规则与红线

- 松紧以能轻微活动为度,不勒到发麻变色;保留随时可解的说法。
- 皮带材质可描写(皮质/布面)但不写摩擦破皮。
- 缚手时间与责罚/训话时长对应,单回合内完成松绑。

## 应用场景示例

### 示例一:夜训中的绳缚(主从关系)

- **设定**:主从同居,睡前例行"回报今日"环节,角色今日顶撞了主人。
- **展开**:先定过错与处置 → 命令跪好,从手腕开始绕绳,边绑边交代松紧("手指还能动,但别想跑了")→ 缚好后维持训话,角色想搓手取暖却办不到,只能老实听训 → 训话结束按序松绑,揉着手腕上的绳痕罚站十分钟。
- **收尾**:以"明天还要绑一次,想清楚说什么"结束,角色低头默认。

### 示例二:皮带捆手 + 责罚(责罚前置绑定)

- **设定**:师生关系,角色考试作弊被抓,导师用皮腰带处置。
- **展开**:要求双手背后交腕,抽出皮带穿过扣环收紧 → 角色被迫保持站姿听训,想挡腮帮子也挡不住 → 皮带捆手状态下接受打屁股,躲闪空间有限,只能绷紧挨着 → 解带后手掌留了印痕,导师揉着手腕说"手是记性最差的地方"。
- **收尾**:罚站十分钟看悔过书,腕上红印第二天才消——这成了"教训"的具象化。
