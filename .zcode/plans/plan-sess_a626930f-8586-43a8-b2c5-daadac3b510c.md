## 重启 4569 端口上的开发服务器

**背景**：`nuxt.config.ts` 中 dev 端口固定为 4569；当前 PID 49161（node/nuxt dev server）正监听该端口。

**步骤**：
1. 结束占用 4569 端口的进程：`lsof -ti :4569 | xargs kill`（含其子进程，避免残留）。
2. 等待端口释放（轮询确认 4569 不再被监听）。
3. 在项目根目录后台启动开发服务器：`pnpm dev`（后台运行）。
4. 确认新进程已监听 4569，且服务响应正常（如 curl 首页 / health 接口）。
5. 按全局约定，重启后的 dev server 保持运行，不关闭。
