## 目标

参考 nuxt-ui-templates/dashboard，为 AISpankWorld 制作「主题色切换」功能：在顶栏加一个调色板下拉按钮，可切换**主色**（primary，17 色）与**中性色**（neutral，4 色），并做 **localStorage 持久化 + SSR 防闪回**（这是对模板的增强——模板本身刷新会丢主题色）。

## 实现机制（复用 @nuxt/ui v4 内置能力，无需手写 CSS）

- 主色/中性色本质就是 `appConfig.ui.colors.primary / neutral`。@nuxt/ui 的 colors 插件（已确认本机 node_modules/@nuxt/ui/dist/runtime/plugins/colors.js）会用 useHead 注入 `style#nuxt-ui-colors`，生成 `--ui-color-primary-50: var(--color-green-50, 回退值)` 这类变量；语义色链 `--ui-primary → --ui-color-primary-500 → --color-green-500`。改 appConfig 即全站即时变色。
- 持久化 + 防闪烁（FOUC）需要自己补：切换时写 localStorage，首次加载时用内联脚本在绘制前把默认色替换成持久化色。

## 文件改动

### 1. 新建 `app/composables/useThemeColor.ts`
- computed getter/setter 包装 `appConfig.ui.colors.primary` 与 `appConfig.ui.colors.neutral`
- setter：改 appConfig（即时变色）+ `localStorage.setItem('nuxt-ui-primary' / 'nuxt-ui-neutral', value)`

### 2. 新建 `app/plugins/theme-color.ts`
- **server 侧**：用 `useServerHead`（tagPriority -1，确保排在 colors 插件的 critical style 之后）注入一段内联防闪回脚本：执行时把 `style#nuxt-ui-colors` 里 `--ui-color-primary-*` / `--ui-color-neutral-*` 变量引用的颜色名（`var(--color-green-500, …)`）通过正则替换成 localStorage 持久化的值；若 style 标签尚未注入则用 MutationObserver 兜底。
- **client 侧**：插件 setup 阶段（hydation 组件渲染前）从 localStorage 回填 `appConfig.ui.colors.primary / neutral`，保证 hydration 后 CSS 直接是持久化颜色。

### 3. 新建 `app/components/ThemeColorDropdown.vue`
- 入口按钮：`UButton`（`color="neutral" variant="ghost" icon="i-lucide-palette"`，aria-label="主题色"），与 UColorModeButton 相邻
- `UDropdownMenu` 两个子菜单（参考模板 UserMenu 的 Theme 结构）：
  - **主题色 Primary**：17 色 `red…rose`（与模板一致）
  - **中性色 Neutral**：`slate / gray / zinc / stone`（不含 `neutral`，避开 v4 的 old-neutral 特例）
- 每个选项：`type: 'checkbox'` + `checked` 标记当前选中；`slot: 'chip'` + `#chip-leading` 具名插槽渲染色点（`bg-(--chip-light) dark:bg-(--chip-dark)`，颜色值 `var(--color-${c}-500 / -400)`）
- `onSelect` 中 `e.preventDefault()` 保持菜单不关闭，再赋新值（走 useThemeColor setter → 变色 + 持久化）

### 4. 修改 `app/layouts/default.vue`
- 在 `UHeader` 的 `#right` 插槽、`<UColorModeButton />` 之前插入 `<ThemeColorDropdown />`

## 明确不做

- 不改 `app.config.ts`（默认仍是 primary: 'green'、neutral: 'slate'）
- reader 布局是沉浸式裸全屏阅读页，不加入口（阅读页已有独立的 ReaderColorField 专属设置）
