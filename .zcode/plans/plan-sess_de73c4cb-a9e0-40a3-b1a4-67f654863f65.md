## 目标
把"性欲"拆成双参数：**性欲强度**（静态特质，留在人物卡，低值=性冷淡）+ **性欲值**（动态状态，随心情/情景/挑逗变化）；**戳中人物嗜好的玩法大幅加速性欲值累积**；技能"强度进阶"档位由性格/性欲/犯错大小/认错态度决定；修复 kinks 只取前 4 条丢失问题。

## A. 双参数数据模型（shared/novel.ts）

1. `CharacterCard.desire` 字段不变（零迁移），注释更新为"性欲强度 0-100 静态特质,低=性冷淡"。
2. `GameState` 新增 `desires?: Record<string, number>`（角色名 → 性欲值 0-100，动态状态，随整局存档/回滚/上云自动兼容）。
3. `TurnStructured.state_delta` 新增 `desires?: Record<string, number | { delta: number, kink?: string }>`（增量，可附触发玩法名）。

## B. 动态性欲值引擎（shared/game.ts）

4. `TURN_OPTIONS_SCHEMA` 增加：`"desires": {"角色名": "性欲值整数增量(可为负);或 {"delta":增量,"kink":"触发玩法名,如 打屁股"} 以便按人物卡嗜好放大"}`。
5. `mergeState(prev, delta, cards?)` 新增 desires 合并，代码级实现变化曲线：
   - 原始增量钳制 ±30；基础缩放 = (角色性欲强度 ?? 50)/50（0.2~2.0）× (1 + 当前性欲值/100)（1.0~2.0 加速）
   - **嗜好命中放大（仅正增量）**：条目带 kink 时与人物卡嗜好匹配（玩法名与 theme 互相包含即命中，多条命中取最高档）——`喜欢 ×2.5`、`接受 ×1.2`、`无感/未知/未命中 ×1.0`、`厌恶 ×0.3`（几乎不涨）
   - 新值 = clamp(当前 + round(增量×基础缩放×嗜好放大), 0, 100)
   - 效果：性冷淡波动极小；低值难涨、高值加速；戳中"喜欢"的玩法性欲值暴涨推进情节，戳中"厌恶"几乎无反应。
6. 新增 `ensureDesires(state, cards)`：为缺失角色播种初始性欲值 = round(性欲强度×0.3)（未知强度→0）。
7. `cardBrief` 修复 kinks：去掉 `.slice(0, 4)` 全量注入并带 detail（利于不 OOC）；性欲标签改"性欲强度X(数值)"。

## C. 强度阶梯与嗜好规则（shared/game.ts buildTurnPrompt）

8. adultMode 规则（143 行）扩展：
   - 性欲值动态说明："性欲值(0-100,见游戏状态 desires)随心情、情景与被挑逗程度动态变化:性欲强度低的角色波动小、难以被挑起;性欲值低时上涨缓慢,一旦升高后续上涨加速;戳中角色嗜好『喜欢』的玩法会大幅加速性欲值累积,『厌恶』的玩法几乎无法累积。"
   - 强度阶梯判定："技能『强度进阶』档位由 ①角色性格 ②性欲强度 ③当前性欲值 ④本回合犯错大小 ⑤认错态度 综合决定:性冷淡/低性欲值用低档,犯错大且认错态度差可跳高档,档位变化要有铺垫、逐级推进。"
9. skillRules 总纲（128 行）追加："技能内『强度进阶』按上述强度阶梯规则选档;角色人物卡嗜好标注『厌恶』的玩法,该角色不主动启用。"

## D. 页面接线
