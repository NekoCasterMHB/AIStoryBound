# 上传/导入 TXT：自动转 UTF-8 + 预览确认 + 特征码基于转换后内容 + R2 存转换后文本

## 需求（已确认）
1. 生成页上传 txt 后自动展示转换后预览（含识别编码标签）
2. 自动识别编码并转 UTF-8（现有 detectNovelEncoding，展示其结果）
3. 特征码基于转换后内容（非原文二进制），前后端同口径
4. **R2 存自动转换后的 UTF-8 文本**
5. **书架导入 TXT：自动转换 + 预览确认后再入库**

## 现状
- 前端 `parseLocalNovel`（worldGen.ts）已识别编码+解码+清洗，与服务端 `parseNovelBytes` 同实现同清洗规则；但生成页确认页不展示预览/编码。
- 特征码：前端 `hashFile(file)` 哈希原始字节；服务端 `upload.post.ts` `sha256Hex(bytes)` 哈希原始字节并 `bucket.put(sourceKey, bytes)` 存原始字节。
- 书架导入：`works.vue onFileChosen` → `parseLocalNovel` → 直接 `saveImported`，无预览、无编码展示。
- R2 读取端 `fetchSourceText` 用 `parseNovelBytes` 解析——对已是 UTF-8 的内容幂等无害。

## 改动

### 1. `app/utils/worldGenCloud.ts`
- 新增 `hashText(text: string)`：`TextEncoder` 编码为 UTF-8 → SHA-256 hex。
- `hashFile` 保留但 generate 页不再使用（改走 hashText）。

### 2. `app/pages/generate.vue`（生成页）
- `handleFile` 解析成功后：`cloudHash.value = await hashText(parsed.chapters[0].content)`（转换后清洗文本）；记录 `uploadMeta = ref<{ encodingLabel, preview } | null>`（`NOVEL_ENCODING_LABELS[parsed.encoding]` + 前 400 字）。
- `refreshDupHit` 改用已算好的 `cloudHash.value`。
- confirm 模板新增「内容预览」卡片（仅上传 txt 路径）：顶部 `<UBadge>` 显示识别编码（如「GBK 已转换为 UTF-8」）+ 小字「按转换后内容生成特征码」；正文 `line-clamp-6 whitespace-pre-wrap` 预览 + 超长省略提示。

### 3. `server/api/world-gen/upload.post.ts`（R2 存转换后内容）
- hash：`parseNovelBytes(bytes, filename)` → `new TextEncoder().encode(parsed.text)` → `sha256Hex`（不再哈希原始字节）。
- R2：`bucket.put(sourceKey, utf8Bytes)` 存转换后的 UTF-8 文本。
- `chars` 防虚报上限由 `bytes.length` 改为 `parsed.text.length`（与客户端 totalChars 同口径）。

### 4. `app/pages/works.vue`（书架导入）
- `onFileChosen` 解析后不再直接入库：设置 `importPreview = ref<{ title, encodingLabel, preview, chapters, author? } | null>` 并打开「导入确认」模态框——显示识别编码徽标（如「GBK 已转换为 UTF-8」）、转换后预览（前 400 字，`line-clamp-6 whitespace-pre-wrap`）、字数；用户点「确认导入」才 `saveImported`，取消则丢弃。
- 新增「导入确认」`UModal`（复用粘贴弹窗风格）。
- 粘贴文本 / ZIP 导入路径不受影响（粘贴本身是 UTF-8 文本、ZIP 已有结构校验）。

### 5. 不改
- `detectNovelEncoding`/`parseNovelBytes`、world_cache 结构、pull 路径（hash 语义变化后新旧缓存自然分离）。

## 验证
- eslint / typecheck 通过。
- GBK/Big5/UTF-16 txt 上传：生成页显示正确编码标签与可读预览；DevTools 对比 `cloudHash` 与任务行 `sourceHash` 一致；R2 存的是可读 UTF-8 文本。
- 书架导入 TXT：先弹预览确认（含编码），确认后入库。
