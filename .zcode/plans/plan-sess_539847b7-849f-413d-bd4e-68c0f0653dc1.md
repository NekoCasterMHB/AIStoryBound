## 目标

12 本内置预置小说的「成书结果」由管理员预先跑一次生成管线,存为静态 JSON 随站点部署;用户从预置入口进入时直接使用预生成世界,0 token、秒进选角。自定义生成(扣 token)保留为可选。

## 分阶段执行

**阶段 A(本次做完并交付测试)**:完成全部代码改动 + 只预生成第一本《巴掌印》供你端到端测试。
**阶段 B(你确认没问题后)**:重跑脚本生成剩余 11 本(脚本默认跳过已有结果,不会重复消耗)。

## 改动清单

### 1. 纯函数下沉共享(保证脚本与浏览器端产物一致)
把 `app/utils/worldGen.ts` 的 `normalizeExtraction`(L96)、`emptyExtraction`(L513)、`normKey`(L517)、`quoteByChapter`(L522)及成书后处理回填(L450-482,抽为 `finalizeCards`)移到 `shared/world-build.ts`,worldGen.ts 改为 import,行为不变。

### 2. 预生成脚本 `scripts/prebuild-presets.ts`(新)
- package.json 加 `"prebuild:presets": "tsx scripts/prebuild-presets.ts"`;参数:`--eco`、`--only=<id1,id2>`、`--force`(默认跳过已有结果,可断点续跑)。
- 配置:先尝试 `process.loadEnvFile('.env')`(Node 内置,失败忽略),再读 env 的 `AI_API_KEY/AI_BASE_URL/AI_MODEL`(默认值同 `server/utils/ai.ts`);缺 key 时明确报错退出。
- 数据:读 `public/txt/*.txt`(跳过 index.json),`parseNovelBytes` 切章,index.json 覆盖标题/作者/题材。
- AI 调用:`buildUpstreamRequest(relay, { messages, json, maxTokens, temperature, stream: false })` 直连上游,解析 `choices[0].message.content`(`extractJson`)+ `usage.total_tokens` 计费;429/5xx/网络错误退避 1.5s 重试一次。
- 管线(完整模式默认,与浏览器端逐阶段一致):`splitUnits` → 并发 4 提取 → `mergeExtractions` → `verifyQuotes` → `buildCheckMessages` 一致性检查(新冲突 `quoteByChapter` 回填)→ `buildSynthesizeMessages` 成书 + `finalizeCards`;`--eco` 走 `buildEcoSynthMessages` + `buildLocalCards`。
- 产出:每本写 `public/worlds/<id>.json`:`{ id, title, author, genre, summary, characters, entities, conflicts, warnings, tokensUsed, mode, generatedAt, version: 1 }`(不含章节正文)。逐本打印消耗与合计。

### 3. 服务端 API
- 新增 `server/api/presets/[id]/world.get.ts`:dev fs 读 / 生产 `env.ASSETS.fetch` 读 `public/worlds/<id>.json`(同 download.get.ts 模式),缺失 404,公开免登录。
- 改 `server/api/presets/index.get.ts`:每行附加 `hasWorld: boolean`。

### 4. 客户端「直接开始(0 token)」
- 新工具 `app/utils/prebuiltWorld.ts`:
  - `fetchPrebuiltWorld(presetId)`:`$fetch('/api/presets/<id>/world')`,404 返回 null。
  - `installPrebuiltWork(presetId)`:拉世界 + `loadPresetChapters(id)` 取章节 → 组装 `LocalWork { id: uuid(), title, author, createdAt/updatedAt, chapters, syncStatus: 'local', tokensUsed: 0, entities, conflicts, warnings, overlay }` → `saveWork` → 返回 workId。
- `app/pages/presets/[id].vue`:有预生成世界时新增主按钮「直接开始 · 官方世界(0 token)」→ 登录 → `installPrebuiltWork` → 跳 `/play/<workId>`;「用这本小说生成世界」保留为次级。
- `app/pages/works.vue` 推荐卡片:有 `hasWorld` 时加「直接开始」按钮(同一入口)。
- `app/pages/generate.vue` confirm 页(from=preset 且有世界):横幅「本书已有官方预生成世界 · 0 token 直接进入」+ 按钮,下方保留「自定义生成」。
- 预生成作品 `tokensUsed: 0`,书架不显示「已消耗」徽章。

### 5. 验证与测试流程
- `pnpm typecheck` + `pnpm build` 通过。
- 阶段 A:带密钥跑 `tsx scripts/prebuild-presets.ts --only=巴掌印`(完整模式,预计 10~15 次调用),产出 `public/worlds/巴掌印.json` 后交给你测试:预置详情页/书架卡片/生成页入口 →「直接开始」→ 选角进入故事,全程 0 token。
