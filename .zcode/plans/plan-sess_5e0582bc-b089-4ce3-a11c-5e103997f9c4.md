## 目标

全链路(本地作品 + 预置书)不再按章节切分,统一存单段全文;删除旧格式预置数据并重建;书架对旧格式作品弹窗建议重新生成。

## 线上用户影响(已确认的事实)

- 已安装预置作品/自传作品/游戏存档:向后兼容,不受影响;重新安装预置书才变为单段格式。
- 预置书阅读进度会重置(chapterIndex clamp 回 0,代码已有保护)。
- 部署顺序约束:新代码必须与新 worlds JSON、重灌后的 D1 同批上线,否则过渡期新安装的预置作品细纲窗口错位。

## 一、本地作品链路

1. `app/utils/worldGen.ts`:`parseChaptersFromText` → 重命名 `toContentSegments`,清洗后不再调 `segmentChapters`,返回 `[{ title:'', content: 全文 }]`;`parseLocalNovel` 同步;`extractFrontMatter` 保留(作者识别启发式用)。
2. `works.vue` 粘贴导入、`edit/[id].vue` flushSave 改用新函数(否则编辑一次又切成多章)。
3. generate.vue 确认页/完成页去掉"N 章";works.vue 作品卡片"N 章"改为字数。
4. **旧格式弹窗(本次新增)**:`works.vue` L826-833 "选择角色"按钮由 `:to` 改为 `@click` 拦截——`w.chapters.length > 1`(旧分章格式)时弹 `UModal`:"该作品为旧版分章格式,建议重新生成世界后再开始",提供「重新生成世界(推荐)」(→ `/generate?from=work&id=`)与「仍然继续」(→ `/play/`)两个操作;单段与空数组(云端恢复态)直接放行。判定依据:旧的"无章节 txt"在旧版也存单段,与新格式无实质差异,无需提示。"继续游戏"(openContinue)不拦截——旧存档与旧作品数据自洽。

## 二、预置书链路单段化

1. `server/utils/novel-parser.ts` `parseNovelBytes`:不再 `segmentChapters`,返回 `{ encoding, text, totalChars }`(调用方仅两个 seed/prebuild 脚本)。
2. `scripts/seed-presets.ts`:不再计算/写入 `chapter_count`(表列保留 dormant);数据源仍为 `public/txt/*.txt`(本来就是全文,不动)。
3. `scripts/prebuild-presets.ts`:提取输入改为全文单段(`splitUnits` 按字数切块,与章节数无关)。
4. `app/utils/chapters.ts` `loadPresetChapters`:返回 `[{ title:'', content: 清洗后全文 }]`;空判断改为按文本空判;删除该文件内 `segmentChapters` 与 `CHAPTER_REGEX` 拷贝。
5. `app/pages/presets/[id].vue`:徽章去掉"N 章"改字数;预览阅读器章节侧栏/翻章按钮/`N / M 章` 在单段时隐藏。
6. `app/pages/read/[src]/[id].vue`:`chapters.length === 1` 时隐藏目录、翻章按钮与"N 章"计数(进度恢复已有 clamp 保护)。
7. `app/pages/works.vue` L47 "读到第 N 章"徽章:仅 `chapterIndex > 0` 时显示。
8. `app/utils/prebuiltWorld.ts`、`shared/novel.ts` 的 `CHAPTER_REGEX`/`segmentChapters`(编辑器锚点、前言/作者识别仍在用)不动。

## 三、删除旧格式预置数据(外部不可逆,明细如下)

1. **D1(本地 + 远程)**:`DELETE FROM preset_novels`(wrangler d1 execute `--local` / `--remote`),再分别跑 `seed:presets:local` / `seed:presets:remote` 重灌。
2. **`public/worlds/*.json`(10 个)**:全部删除,重跑 `npm run prebuild:presets` 重新生成(旧 JSON 细纲 startChar 基于剔除标题行的文本,不重建则窗口错位)。⚠️ 消耗与上次全量生成相当的 LLM token。
3. **客户端 IndexedDB**:预置缓存存原文,无需作废;旧安装的多段作品由上面的弹窗引导,如需清理用户在书架手动删除。
