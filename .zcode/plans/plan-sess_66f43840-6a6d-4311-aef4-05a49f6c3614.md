# 游戏体验优化（test 分支，四个方向全做）

**前提**：games/[id].vue 有用户未提交的改动（startNarrStream 可重入、旧存档兜底等），全部保留，只在其上叠加。`aiChat`/`aiChatJson` 的 AbortSignal 管线已现成，游戏页只是没用。

## A. 游玩交互修复（games/[id].vue 为主）

**A1 回合可取消**：新增 `turnAbort`（AbortController）+「停止」按钮（streaming 期间显示在行动按钮旁）；叙事 `aiChat` 第 4 参、选项 `aiChatJson` 的 `handlers.signal` 传入 signal；`onUnmounted` 时 abort 防止卸载后后台烧 token。catch 里区分 `CancelledError`：不算失败，弹出本回合已 push 的 user 行动消息、恢复上一决策点选项（从 `optionsByMessage` 取最后一条 narrator 的选项）、toast「已停止生成」、persist。

**A2 失败重试**：把选项阶段抽成可重入函数 `runOptionsPhase(narratorMsg)`。error UAlert 加「重试本回合」按钮：
- 叙事失败（最后一条是 user，无旁白）→ 弹出该 user 消息后 `sendTurn(choice)` 重跑
- 收尾失败（旁白已上屏但无选项）→ 只重跑 `runOptionsPhase`
- 选项为空数组时同样显示「本回合没有生成选项」+「重新生成选项」按钮（复用同函数）

**A3 占位区分**：footer 占位按状态显示——`awaitingOptions`「正在生成选项…」/ `streaming`「生成剧情中…」/ 非 streaming 且最后一条是 user「上一条行动未获回应」（附重试按钮）/ 其余「请选择行动或输入」。

**A4 回滚恢复选项**：`rollbackAction` 重建 `optionsByMessage` 后，从恢复点最后一条 narrator 消息回填 `options.value`。

**A5 首回合速度**：`narrSpeed = ref(NARR_SPEED_DEFAULT.cps)`（20，当前是旧档位 60）。

**A6 选项期 token 计数陈旧**：`optionsCall` 传入 `onLive` 继续更新 `liveTokens/liveSpeed`（`aiChatJson` 已支持）。

**A7 互链**：游戏页顶栏加「阅读原著」（`work.chapters` 有内容时 → `/read/work/${game.workId}`）；阅读页顶栏加「进入世界」图标按钮（src=work 且 overlay.characters 存在时 → `/play/${id}`，需在 loadBook 里记录 `hasWorld`）。

**A8 空输入**：`sendInput` 空输入时 toast 提示。

## B. 世界观可见 + 重生成 + 元数据编辑

**B1 新组件 `app/components/WorldDetailModal.vue`**（参考 CharacterCardsModal 的 v-model:open 模式）：props `workId`，内部 `getWork` 加载。分区展示：概览（summary/orientation/heat/setting/tags/tropes/contentWarnings）、故事线（折叠）、实体库（人物/地点/势力/规则/伏笔分组，带原文引用 quote + verified 徽章）、冲突 conflicts、生成告警 warnings。**编辑模式**：概览字段（summary/orientation/heat/setting/tags 等）可改，保存 → 更新 `work.overlay` + synced 置 dirty + saveWork + toast。

**B2 入口挂载**：works.vue「更多」菜单加「世界详情」+ 卡片加实体/冲突/告警计数徽章（点击打开）；generate.vue 完成页加「查看世界详情」次级按钮；play/[id].vue 加入口按钮。

**B3 重新生成世界**：works.vue 菜单加「重新生成世界」→ `/generate?from=work&id=`（无论有无人物卡，管线与 extract 缓存复用都是现成的）。

## C. 书架健壮性（works.vue 为主）

**C1 删除确认 + 孤儿清理**：onDeleteWork 前弹 UModal 确认（提示将同时删除 N 个本地游戏存档）；确认后 `deleteLocalGame` 逐个清理 + gameSaveStore 新增 `deleteGamePoints(gameId)` 清理存盘点 + `deleteWork`。CharacterCardsModal 的 removeCard 也加确认弹窗。
