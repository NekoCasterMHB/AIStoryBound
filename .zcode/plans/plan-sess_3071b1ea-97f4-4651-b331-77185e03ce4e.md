# 修复剧情"回退重复":回注水位化 + 已发生标记

## 根因(已核对代码确认)

"防跑偏"(段回注)每 N 回合把**当前段开头 900 字原文**注入 prompt(`app/pages/games/[id].vue:216-218` 写死 `slice(0, 900)`),而开局回合已让模型从段首逐句演过这批内容——回注等于把几回合前的"剧本"重塞给模型,措辞"须重新演绎"(`shared/game.ts:943`)直接诱导重演;`lastReinjectBeat` 不持久化(`[id].vue:202`),刷新后再次注入。叠加细纲近窗已演段无"已发生"标记(`shared/game.ts:570-580`)、摘要/回注块无防重演声明,形成系统性重复。

## 改动清单

### 1. 回注水位持久化 + 窗口只向前推进(核心)
**`shared/novel.ts`**:`LocalGame` 增加可选字段 `reinject?: { beat: number, pos: number }`(beat=上次回注段下标,pos=该段已注入到的字符偏移)。

**`app/pages/games/[id].vue`**:
- 删除页面级 `let lastReinjectBeat = -1`,改用 `game.value.reinject` 持久化;`onMounted` 随存档读入,`persist()` 写回。
- `buildBeatReinject()` 窗口语义改为水位前进:
  - 段切换(beat 变化)时 `pos` 归零;开局方式为 beat 且开局段=当前段时,初始 `pos` 跳过开局已演的开头(对齐 `game.ts:908` 的 1000 字,取 `min(1000, len)`)。
  - 每次回注:窗口 = `canon.text.slice(pos, pos + 900)`(v1 无 canon.text 则 `joinedText.slice(startChar + pos, …)`),随后 `pos += 900`;`pos >= 段长` 时 window 为空串(仅结构化对照)。
- 同步修正 stale 注释(`[id].vue:201-206`、`984`)与 UI 文案「默认 5 回合」→「默认 8 回合」(`[id].vue:2403`、`app/profile.vue` 同款文案处)。

**`app/utils/gameStore.ts`(行映射,~71-82)、`app/utils/localDb.ts`(~326 行类型)、`app/utils/gameSaveStore.ts`(存档点快照,~18)**:透传 `reinject` 字段,确保存档/回滚与 `currentBeat` 同路径恢复。

### 2. `shared/game.ts` prompt 护栏
- **`trackLines`**:`b.index < currentBeat` 的段(已演过)改为带前缀 `【已发生,勿重演】` 的一行骨架(与远段同压缩),近窗全量只保留当前段及之后 ±2 段;`currentBeat == null` 时维持全量不变(旧存档行为不变)。v1 细纲与角色弧线同路径生效。
- **回注块(925-950)**:
  - window 有值时改标头为「本段后续原文(尚未演绎到的部分,前瞻参考)」,明确"不要回头重演已发生情节,剧情自然推进到该处时再以其为参考";删除"重新演绎"措辞。
  - `beatSummary` 行补注"(含已发生与未发生情节:已演过的不要重演,从未演处继续)"。
  - 页脚(948)补一句"本段开头已在之前回合演绎完成,不要回到段首重演,从当前进度继续向前推进"。
- **剧情回顾块(886)**:`【剧情回顾】` → `【剧情回顾(以下均为已发生事实,只作衔接基础,不要重新演绎)】`。
- **`REINJECT_WINDOW_CHARS` 注释(16 行)**与水位实现对齐。

### 3. 测试与验证
- `shared/game-v2.test.ts` 补/改用例:`trackLines` 已发生段标记与压缩;回注块文案(窗口标头/页脚护栏)断言。
- 手动验证:beat 开局玩 10+ 回合,中途刷新页面再续玩;devtools 看 `/api/ai/chat` 请求体确认——回注窗口从开局已演的 1000 字之后开始、每次回注窗口前进、不再重复出现同一段原文;近窗中已演段带"已发生"标记。

## 不改的部分(明确出范围)
- 12 条历史窗口容量与摘要 800 字上限不动(缓存与成本敏感;A/B 修复后非主因)。
- `advancePlotBeat` 只进不退逻辑不动(防幻觉回跳,方向正确)。
- 取消回合时摘要/状态残留(`[id].vue` 收尾与落盘竞态)为边缘场景,本次不处理。
