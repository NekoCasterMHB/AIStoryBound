## 目标
把「AI Skill 玩法库」的导入/解析从项目自有 JSON 格式改成**市面通用 SKILL.md** 兼容:
- 抛弃 `prompt` 老字段兼容与自有 JSON 导入,改为解析 YAML frontmatter(name+description)+ Markdown 正文;
- 用户粘贴 SKILL.md 直链 → worker 代理抓取正文 + **跟随引用一并抓取同级文件**(多文件 skill)→ 存 IndexedDB;
- 开启的技能**原样注入正文**进游玩叙事引导 AI 更专业回复;
- 内置 18 个玩法**一并补上正文**,让内置玩法也注入细节。

## 改动清单

### 1. 依赖(package.json)
- 新增 `js-yaml`(frontmatter 解析,纯 JS、浏览器/Worker 通用)+ dev `@types/js-yaml`。当前项目无任何 YAML 解析库。

### 2. shared/ai-skills.ts(核心)
- `AiSkill` 新增字段:`body?: string`(SKILL.md 正文)、`attachments?: { name, text }[]`(跟随抓取的同级文件)、`sourceUrl?: string`。保留 `trigger/steps/rules/references` 仅用于兜底读取已存 IDB 的旧条目(不再接受新 JSON 导入)。
- 新增 `parseSkillMd(text): AiSkill`:抽取文件头 `---` 之间 YAML frontmatter(容忍 BOM/前导空行),js-yaml 解析;必填 `name`+`description`,缺任一报中文错误;`key` 由 name 派生(slugify:转小写、非法字符→`-`、去重塌缩);`desc=description`;`body`=第二个 `---` 之后正文(trim 且非空校验)。
- `skillPromptBlocks(skill)`:有 `body` 时返回 `正文:\n<body>` + 各 attachment(`参考文件:{name}\n{text}`);无 body 的旧条目走原结构化渲染。
- **删除** `normalizeSkill` 与 `prompt` 老字段映射;清理未使用的 `aiSkillName/enabledSkillNames`。
- **内置 `AI_SKILLS` 18 个玩法逐一补 `body`**:每个按「触发场景 + 展开步骤 + 规则边界」写一段 120~300 字 Markdown SOP(与人物卡性欲档位/关系设定协调的描写节奏),保留现有 key/name/desc。

### 3. server/api/ai/skill-import.post.ts(worker 代理改造)
- 改为下载**文本**而非 JSON:保留 requireUser、http(s) 直链、15s 超时、单文件 256KB 上限。
- 抓正文后**解析相对引用**:Markdown 链接 `[x](相对路径)` 与 Anthropic 约定 `$SKILL_FOLDER$/路径`(跳过 http(s)/#/data/mailto 与图片/二进制扩展),用 `new URL(rel, 主URL)` 解析;对每个同级 .md/.txt 文件二次抓取(去重、上限 8 个、合并 ≤512KB),失败跳过不致命。
- 返回 `{ url, text, files: { name, text }[] }`,前端负责 frontmatter 解析与校验。

### 4. app/pages/profile.vue
- `importSkillFromUrl` 改为:POST 拿 `{text, files}` → `parseSkillMd(text)` → 组装 `{...parsed, attachments: files, sourceUrl}` → 内置 key 冲突检查 → `saveUserSkill` → 自动开启。
- UI 文案改掉 JSON 示例与 `.json` 占位符,改为「粘贴 SKILL.md 直链(如 GitHub raw / jsdelivr)」;占位 `https://…/SKILL.md`。

### 5. shared/game.ts 注入预算
- 内联正文比旧字段长:单技能截断 440→1000 字符、总预算 2600→6000、最多仍 6 个技能,让真实 SKILL.md 正文完整进 system prompt(菜单行逻辑不动)。

### 6. 示例文件
- `public/ai-skill-example.json` → 替换为 `public/ai-skill-example.md`(frontmatter + 正文,演示新格式;该文件无任何代码/文档引用,可安全替换)。

## 验证
1. `pnpm add js-yaml` + `pnpm add -D @types/js-yaml`,`pnpm typecheck`。
2. 起本地 dev,用一条真实 SKILL.md raw 直链(如 Claude 官方 skill 仓库单文件 + 一个带 reference.md 的多文件示例)测 `/api/ai/skill-import`:
   - 单文件:返回正文,frontmatter 解析出 name/desc/key;
   - 多文件:返回被抓取的同级 .md,attachments 正确;
   - 缺失 name/description 或空正文:友好中文报错。
3. 个人中心导入 → 进 IDB → 开关列表出现 → 开启后进游戏一个回合,确认 system prompt 含该技能正文块与参考文件(调试日志或抓包确认)。
4. 顺手清理启动的 dev server,释放端口(遵循全局规则)。
