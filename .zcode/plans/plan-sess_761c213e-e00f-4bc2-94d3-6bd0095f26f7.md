## 功能一:导航栏"生成世界"按钮移动端隐藏文字

**文件:`app/layouts/default.vue`(第 56-63 行)**

参照同文件上方"我的书架"按钮(第 45-54 行)的现成模式——图标常显、文字用 `<span class="hidden sm:inline">` 包裹、`aria-label` 兜底无障碍:

```vue
<UButton
  color="primary"
  icon="i-lucide-sparkles"
  size="sm"
  aria-label="生成世界"
  @click="onStartGenerate"
>
  <span class="hidden sm:inline">生成世界</span>
</UButton>
```

**效果**:手机端(< 640px)只显示 sparkles 图标,sm 及以上显示"生成世界"文字。

## 功能二:书架页"导入小说"按钮 + 菜单(上传 TXT / 粘贴文本)

**文件:`app/pages/works.vue`**

点击后走**直接导入书架**方案:解析章节 → 存入"本地作品"(IndexedDB works)→ 立即出现在书架可阅读;不调用 AI、不消耗 token、不要求登录。复用现有函数 `parseLocalNovel`(worldGen.ts:42,编码检测+分章)、`parseChaptersFromText`(worldGen.ts:50)、`saveWork`(worldGen.ts:347)和 `uuid`(shared/novel.ts:427)。

### 1. 顶部操作区新增"导入小说"按钮(菜单)
在"生成新世界"与"返回首页"之间(第 159 行后)插入,用 `UDropdownMenu`(与 default.vue 用户菜单同款用法):

```vue
<UDropdownMenu :items="importMenuItems">
  <UButton
    label="导入小说"
    icon="i-lucide-upload"
    color="primary"
    variant="soft"
    size="sm"
  />
</UDropdownMenu>
```

菜单两项:
- `上传 TXT`(icon: i-lucide-file-text)→ 触发隐藏文件输入
- `粘贴文本`(icon: i-lucide-clipboard-paste)→ 打开粘贴弹窗

### 2. 上传 TXT
照 generate.vue 第 157-163 行模式加隐藏输入(accept=".txt,.text"),选中后 `parseLocalNovel(file)` 拿到 `{ title(文件名), encoding, chapters }` → 直接落库。

### 3. 粘贴文本弹窗
`UModal`(v-model:open + title,与 AuthModal.vue 第 233 行同款):
- 可选"书名" `UInput`(空则默认取第一章标题,再无则"未命名小说")
- 正文 `UTextarea`(rows≈12,placeholder 说明自动按章节切分)
- 底部"取消 / 导入"按钮,导入中按钮 loading 防重复

### 4. 落库与反馈
```ts
const work: LocalWork = {
  id: uuid(),
  title,
  createdAt: new Date().toISOString(),
  chapters,
  encoding?,        // 上传 TXT 时带
  syncStatus: 'local'
}
await saveWork(work)
```
之后 `refreshLocal()` 刷新列表,并把 UTabs 切到"个人书架"tab(给现有 `shelfTabs` 补 `key`、加 `v-model="activeTab"`,新书立刻可见),最后 `useToast`(Nuxt UI 全局提供,app.vue 的 UApp 已挂载)提示"已导入《书名》"。解析失败(如空文本)catch 后 toast 报错。
