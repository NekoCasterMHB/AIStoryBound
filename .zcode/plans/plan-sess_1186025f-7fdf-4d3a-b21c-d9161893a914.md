## 为 AISpankWorld 实装 PWA(可安装 + 离线缓存)

项目现状:Nuxt 4.5.2 + @nuxt/ui,部署到 Cloudflare Workers(静态资源经 `wrangler.toml [assets]` 托管 `.output/public`)。目前零 PWA 依赖,且有两处"主动禁用 SW"的历史代码需要清除。图标源用现成的 `public/图标.png`。

### 实施步骤

**1. 安装依赖**
- `pnpm add -D @vite-pwa/nuxt`(最新 1.1.1,内部用 vite-plugin-pwa ^1.2.0)
- 安装后检查 pnpm 对 nuxt 4.5.2 / Vite 的 peer 警告;若模块运行时与 Nuxt 4 不兼容(实测发现问题),回退方案是手工集成 vite-plugin-pwa + 自写注入插件,但预期不需要。

**2. 清除反 SW 历史代码**
- 删除 `app/plugins/unregister-sw.client.ts`(启动时注销所有 SW,会杀掉新注册的 PWA SW)
- 删除 `public/dev-sw.js`(自我注销的 SW 桩,不再需要)

**3. nuxt.config.ts 添加 PWA 模块与配置**
- modules 数组加 `'@vite-pwa/nuxt'`
- 配置块:`registerType: 'autoUpdate'`(静默自动更新)、`workbox.globPatterns` 覆盖 `js/css/html/ico/png/svg/woff2/txt`(txt 为预设小说,precache 后离线也能读)、`cleanupOutdatedCaches: true`、`devOptions.enabled: false`(dev 不注册 SW,避免干扰开发)
- manifest:name/short_name「AISpankWorld」、`lang: zh-CN`、`display: standalone`、`start_url: '/'`、`theme_color: #00C16A`(品牌绿,与 main.css 的 Nuxt UI primary 一致)、`background_color: #ffffff`,icons 指向生成的 192/512/maskable PNG

**4. 生成图标**(新增 `scripts/generate-pwa-icons.mjs`,源为 `public/图标.png`)
- 生成 `public/pwa-192x192.png`、`public/pwa-512x512.png`、`public/maskable-512x512.png`(512,内容居中加安全边距)、`public/apple-touch-icon.png`(180x180)
- 转换工具:优先系统已有的 ImageMagick/ffmpeg;都没有则临时 `pnpm add -D sharp` 跑脚本(脚本保留,未来换图标可重跑)

**5. head 补充**(视模块自动注入结果)
- @vite-pwa/nuxt 会自动注入 manifest link、theme-color、注册脚本;若构建后 HTML 缺少 apple-touch-icon / mobile-web-app-capable,在 `app/app.vue` 的 useHead 中手动补上

**6. SW 缓存策略优化**:新增 `public/_headers`,为 `/sw.js` 设 `Cache-Control: no-cache`(避免 Cloudflare Assets 的默认缓存拖延 SW 更新检查);构建后验证该文件被复制进 `.output/public`(Nuxt 会复制 public 全量,预期可行;若被过滤则改用 worker 中间件方案)

### 验证
1. `pnpm dev`(先查 4569 端口占用,按全局规则杀旧启新),确认页面正常、无 SW 报错、`/manifest.webmanifest` 可访问、DevTools Application 面板 Manifest 有效
2. `pnpm build:cf` 构建,确认 `.output/public` 下有 `sw.js`、`manifest.webmanifest`、图标与 `_headers`
3. 浏览器验证:本地预览构建产物,检查 SW 注册成功、Network 面板能看到 precache 拉取、离线模拟(Application → Service Workers → Offline)能打开应用壳
4. 完成后关闭 dev server 释放端口

### 说明
- 这是 SSR + API 动态应用,离线时数据接口不可用属预期:PWA 提供的是"可安装 + 打开壳 + 静态资源/precache 内容离线可用"(含预设小说 txt);在线时自动更新到最新版本。
- 不改动任何业务逻辑、路由、数据层。
