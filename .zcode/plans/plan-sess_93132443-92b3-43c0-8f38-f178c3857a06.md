# 创意工坊页面实现方案(修订版:小说同款版本管理)

## 存储方案:小说正文存 R2,元数据存 D1
- **正文(TXT)存 R2**(复用现有 SKILL_FILES bucket):每个版本一个文件 `novels/<sellerId>/<id>-v<version>.txt`,与 skill 的 `skills/<sellerId>/<id>-v<version>.zip` 完全同款
- **原因**:D1 单行/单值上限 2MB([Cloudflare D1 官方限制](https://developers.cloudflare.com/d1/platform/limits/)),中文小说 UTF-8 下几十万字即超限;R2 无此限制,且与 skill 存储模式一致,R2 读写/流式下载代码可整套复用
- D1 只存元数据(标题/价格/预览字数/状态/版本快照),列表查询轻量

## 〇、附带调整:skill zip 上限 10MB → 1MB
- `shared/store-skill.ts`:`MAX_SKILL_ZIP_BYTES` 常量 10MB → 1MB(服务端 store/skills.post.ts、admin/skills/publish.post.ts 均引用该常量,一处改动生效)
- 前端同步:store/publish.vue 与 admin/skills.vue 发布弹窗的客户端 zip 大小校验改为引用/对齐 1MB,提示文案同步

## 一、数据层(server/db/schema.ts + drizzle/init.sql)

仿 skill 三表结构,新增:

**novel_products**:id、sellerId(FK user)、title、author(可空)、desc、price(整数 token)、previewChars(当前主版本的可预览字数)、status(pending/approved/rejected/removed)、rejectReason、featured、downloadCount、purchaseCount、mainVersion(手动固定展示版本)、reviewedBy、reviewedAt、createdAt、updatedAt;索引 sellerId、status+featured

**novel_product_versions**:id、novelId(FK cascade)、version(自增从 1)、title/author/desc/price/previewChars 快照、fileKey/fileName/fileSize、status(版本级)、rejectReason、enabled(1/0)、reviewedBy、reviewedAt、createdAt;唯一索引(novelId, version)

**novel_purchases**:id、novelId(FK cascade)、buyerId(FK)、price、sellerShare、platformFee、novelVersionId(购买锁定的版本)、createdAt;唯一索引(novelId, buyerId)幂等

init.sql 追加三张表 CREATE TABLE(部署时对现有 D1 执行迁移)。

## 三、服务端 API(完整镜像 skill 商城,含版本管理)

**商店端**:
- `GET /api/store/novels` — 公开列表(approved 且有 ≥1 个 approved+enabled 版本),免费优先/推荐/最新;登录带 owned
- `POST /api/store/novels` — 发布/更新(multipart:title、author、desc、price、previewChars、file txt、novelId?)。首次:商品+v1 均 pending;更新:版本=max+1 新版本 pending、**价格强制沿用主表价格**(同 skill,更新不能改价)、旧 approved 版本继续售卖。校验:字节≤10MB、字数≥500、0≤previewChars≤总字数且≤100000、更新需归属校验
- `GET /api/store/novels/mine` — { purchased, published }(静态路由优先于 [id])
- `POST /api/store/novels/[id]/purchase` — 克隆 skill 购买:锁定最新 approved+enabled 版本,单 db.batch 条件扣款(余额不足 402)→ 卖家 80% → purchaseCount+1 → 插入 novel_purchases;已购幂等
- `GET /api/store/novels/[id]/download` — ?version= 可选;买家默认锁定版本、可下已购版本+任意 approved+enabled 版本,卖家/管理员任意版本;未购买 403;downloadCount+1
- `GET /api/store/novels/[id]/preview` — 公开:最新 approved 版本元信息 + 正文前 previewChars 字(UTF-8 解码,非 UTF-8 字数近似)+ totalChars + canViewAll;已购/卖家/管理员可看全文
- `POST /api/store/novels/[id]/status` — 下架/重新上架(removed ↔ pending 送审)
- `POST /api/store/novels/[id]/version` — 卖家版本管理:main 固定展示版本 / enabled 开关(主版本不可禁用),同 skill

**管理端**(requireAdmin):
- `GET /api/admin/novels` — 商品+最新版本联查,?status= 筛选,含卖家/推荐/拒绝原因/版本号
- `POST /api/admin/novels/[id]/review` — 通过最新 pending 版本(同步 title/author/desc/price/previewChars 到主表、mainVersion=最新、approved)/拒绝(必填 reason,旧 approved 版本继续售卖)/推荐 featured
- `GET /api/admin/novels/[id]/preview` — 最新版本元信息 + 正文前 ~50KB 供审核
