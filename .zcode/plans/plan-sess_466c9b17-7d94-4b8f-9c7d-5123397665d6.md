采用"取消自动安装 + 手动下载 + 已安装提示覆盖"方案,从源头消除云端成书重复落库问题。现有缓存机制(确认页点生成前查重、拉缓存由用户决定)保持不动。

## 根因回顾
重复成书 100% 在客户端:downloadAndInstallWorldTask 每次调用 importWorkFromBytes 生成新 uuid + saveWork 落一条,非幂等。最大重复源是双页自动安装竞态:生成页轮询完成自动安装(generate.vue:302)+ 书架页轮询自动安装(works.vue:387-389)在任务完成瞬间各落一条;此外书架任务卡可反复手动点击再落多条。

## 改动(5 处,全部客户端)

1. shared/novel.ts:LocalWork 增加可选字段 sourceTaskId?: string(标记作品来源任务 id,用于手动下载时判定已安装;旧数据兼容)。

2. app/utils/worldGen.ts:新增 getWorkBySourceTask(taskId) 辅助函数,按 sourceTaskId 查 works 表。

3. app/utils/worldGenCloud.ts:downloadAndInstallWorldTask 增加选项 opts?: { onDuplicate?: (existing: LocalWork) => Promise<boolean> }。安装前先 getWorkBySourceTask(task.id):已存在且传入 onDuplicate 时由调用方弹确认框决定覆盖(重新下载 zip 覆盖更新、保留原 id)或跳过(不落库,返回已存在作品);未传 onDuplicate 时静默返回已存在作品。

4. app/pages/generate.vue:
   - startCloudGeneration(251-325):轮询到 completed 后取消自动安装,保存任务快照、phase='done' 但 resultWork=null;完成页改为展示「云端任务已完成」+ 新增「下载安装并进入」按钮,点击后调用 downloadAndInstallWorldTask(final, { onDuplicate }) 落库并 navigateTo(/play/{work.id});onDuplicate 命中时弹「本地已有《title》,是否覆盖?」。
   - startPullCached(328-353):保留(用户显式点击「拉取已有世界」后的直接结果,无竞态)。

5. app/pages/works.vue:
   - 删除 loadCloudTasks 中的自动安装段(works.vue:385-391),轮询仅刷新任务列表;installedTaskIds 内存 Set 一并删除。
   - 任务卡「下载安装」按钮(works.vue:404 手动路径)改为调用 downloadAndInstallWorldTask(t, { onDuplicate }):已安装时弹「本地已有《title》,是否覆盖?」,确认→覆盖更新,取消→toast「已跳过,保留本地已有作品」;未安装则正常下载安装并 toast 成功。

## 验证场景
- 传 TXT 生成,完成瞬间同时在 /generate 与 /works 停留 → 书架不出现任何作品(不再自动安装),生成页显示「任务已完成」;
- 生成页点「下载安装并进入」→ 书架落一本并跳转选角页;
- 书架任务卡再点「下载安装」→ 弹「是否覆盖」提示,确认覆盖同一条记录不新增,取消保留现有;
- 拉取已有世界 → 落一本;
- 多标签页各轮询 → 均不再自动安装,无重复。

- 确认页 refreshDupHit / checkWorldDuplicate(上传 txt 点击生成前检测)——原样保留;
- 「拉取已有世界」按钮与 startPullCached 半价扣费——原样保留;
- 服务端 world_cache / world_gen_tasks / R2 逻辑——不动。
