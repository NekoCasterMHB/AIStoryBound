## 预置小说功能实施计划（修订版：docs/txt + IndexedDB 预览缓存）

### 目标
预置小说 TXT 存 R2、D1 建索引；首页推荐列表展示（默认数据 = docs/txt 下你准备的小说）；点击"预览"自动下载 TXT 并保存到 IndexedDB 持久化，阅读页从本地缓存渲染；"用这本小说生成世界"以正文为上下文复用现有 AI 世界观生成链路。

### 1. 数据层（D1 + 迁移）
- `server/db/schema.ts` 新增 `preset_novels` 表：id（文件名主键）、title、author、genre、description（推荐语）、cover_emoji、cover_color、storage_key（R2：`presets/<id>.txt`）、encoding、chapter_count、char_count、featured、sort_order、download_count、created_at。
- `pnpm db:generate` 生成 `drizzle/0002_*.sql`；新增 `scripts/d1-migrate.mjs`（顺序执行 drizzle/*.sql），`package.json` 的 `db:migrate:local/remote` 改指它。对 local + remote D1 各执行迁移。
- 顺带修复：`server/utils/db.ts` 的 `insertChapters` 按 ≤20 行/批分块插入（D1 单语句 100 绑定上限；两本书章节数多，现有上传流程同样会踩，分块一并解决）。

### 2. 共享类型与工具
- `shared/novel.ts` 增加 `PresetNovelRow` 接口。
- `server/utils/db.ts`：`getPresetNovel` / `listFeaturedPresets` / `incrementPresetDownloads`。
- 新增 `server/utils/r2.ts`：`getR2Binding(event)`、`getPresetTxtBytes(event, storageKey)`（对象缺失抛 404）。
- 重构：抽取 `server/api/novels/index.post.ts` 生成核心到 `server/utils/novel-generation.ts`（`createGenerateSseResponse` + `generateNovelWorld`，完整保留编码检测、章节切分、60k 字符 AI 上下文上限、token 实时计数、JSON 兜底重试）；上传接口变薄壳，行为不变。

### 3. API
- `GET /api/presets` — 首页推荐列表（featured=1 按 sort_order）。
- `GET /api/presets/[id]` — 详情。
- `GET /api/presets/[id]/download` — 流式返回 R2 TXT + `Content-Disposition: attachment`，累加 download_count（预览页 fetch 同用它取文本）。
- `POST /api/presets/[id]/generate` — SSE：校验预置存在且 R2 可读 → `generateNovelWorld` 以正文为上下文，done 携带新建 novel_id。
- 不做章节 content 端点：阅读由客户端解析（segmentChapters 为共享纯函数，浏览器可用）。

### 4. 前端（预览 → IndexedDB 持久化）
- `app/utils/localDb.ts`：DB_VERSION 2→3，新增 `presets` store（keyPath: id）。
- 新增 `app/utils/presetStore.ts`：`getCachedPreset(id)` / `saveCachedPreset(id, meta, text)`。
- `app/pages/index.vue`：顶部"预置小说推荐"区——卡片（封面 emoji、标题、作者、章数/字数徽标、推荐语）+ 操作按钮：**预览**（→ /presets/[id]）、下载 TXT、生成世界；下方保留原上传卡片。
- 新增 `app/pages/presets/[id].vue` 预览/阅读页：
  - 挂载时先查 IndexedDB 缓存 → 未命中则 fetch download 端点取全文 → 写入 IndexedDB → 客户端 segmentChapters 切章渲染（大屏章节侧栏 / 小屏下拉 + 上一章/下一章按钮），显示"已缓存到本地"徽标；
  - 下载 TXT 按钮（直链）；
  - "用这本小说生成世界"按钮 → 内嵌 SSE 进度（token/速度/耗时）→ done 后跳转 `/novels/<novelId>/select`，失败可重试。

### 5. 种子数据与脚本（读取 docs/txt）
- 新增 `scripts/seed-presets.ts`（devDependencies 加 `tsx`），默认扫描 `docs/txt/*.txt`：
  - id = 文件名去扩展名；storage_key = `presets/<id>.txt`；
  - 元数据自动解析：首行 `《标题》作者：XXX`、首个短段落作推荐语；支持可选 `docs/txt/index.json` 覆盖（title/author/genre/description/coverEmoji/coverColor/featured/sortOrder，不存在则不用）；
  - 本地复用 novel-parser 统计 chapter_count / char_count；
  - 调 wrangler CLI：`r2 object put` 上传 + `d1 execute --file` 插入（--local / --remote）。
- `package.json` 增加 `seed:presets:local` / `seed:presets:remote`；README 补充扩展方式（往 docs/txt 放 txt 重跑脚本即可）。
- 实施时对现有两本（巴掌印、撩愈）执行 local 与 remote 两遍种子；Remote 若无 wrangler 凭据则改用 Cloudflare 账户 API（本会话已配置 accountId）。

### 6. 验证
- `pnpm lint` + `pnpm typecheck`；`pnpm dev` 起服务 curl 验证 /api/presets、download（响应头）、generate（SSE 全流程，用 .dev.vars 的 AI Key）；GUI 验证首页列表、预览→IndexedDB、翻章、生成→选角页。
